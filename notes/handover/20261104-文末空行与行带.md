## 一、一句话

用户三个"污染"入口全部复现并定位成**四处映射错位**：N1 空白行不成段落、N2 删完光标落在下一行、

## 三、N3c 为什么撤回

实测（`$$\n\frac{a-x}{a+x}\n$$`，用竖条高度当"层"的证据）：

| 位点 | 竖条 (y, h) |
|---|---|
| 分子 `a` 之后 | 131.8, 21.0 |
| 分子末 | 135.1, 17.6 |
| **分母末尾** | **162.4**, 17.6 |
| **tex 末尾（`}` 之后）** | **159.0**, 21.0 ← 应在 135.1..162.4 之间的主行带 |
| 块后（`$$` 之后） | 145.2, 20.0 |

⇒ tex 末尾与块后**差 13.8px**，且 tex 末尾贴到了分母（162.4）那一带。

试过的修法：主行位点在"这一层量不到字形"时改用**最外层行盒**（效果：3.27px，接近块后那格）。
**但 `caret_layer_test` 的全域扫描（10 类结构 × 67 个位点）当场给出反例**：

```
「\overline{AB}」rel=0 ：竖条 y 1.3..15.5 与该层字形行 17..17 不相交
「\overline{AB}」rel=13：同上
```

⇒ 判据不能一把梭：**结构节点后面**（`\frac` / `\sqrt` / 环境）该用主行带，而**装饰后面**
（`\overline` / `\underbrace` 这类）的行盒本来就不是主行带。这个区分要单独一轮做，
所以本批**只留数字、不留代码**（红线守卫也未入库，避免红着进主干）。

## 五、手验清单（给用户）

1. `甲⏎⏎⏎乙` 的空行里打几个空格 ⇒ 竖条还在、跟着右移。
2. 新建 → `w` → ⌫ → 打 `a` ⇒ `a` 在**第一行**（不再凭空多一行）。
3. `a⏎⏎b⏎⏎c⏎⏎` 删 `c` ⇒ 光标留在 `c` 那一行（不再下跳）。
4. 分式所在那一行末尾按 Enter ⇒ 只下一行、只多一行。
