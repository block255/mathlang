## 一、一句话

用户三个"污染"入口全部复现并定位成**四处映射错位**：N1 空白行不成段落、N2 删完光标落在下一行、
N3a 行内公式 tex 末尾 Enter 加两行、N3b 文首空行被补 `\n`；**N3c（分式后竖条按分母画）撤回**，
因为全域扫描给出反例。

## 二、逐条（现象 → 根因 → 修法）

| # | 现象（用户实测） | 根因 | 修法 |
|---|---|---|---|
| **N1** | 空行里打空格，竖条**仍然消失** | 上一批只改了 `blank_runs.blankRunFrom`（版面高度那一侧）；**块模型** `LineIndex.isBlank` 还是 `trim()` ⇒ R1 仍把空格行当"空行边界"、不产生块 ⇒ 走空行槽（只在行首画竖条） | `LineIndex.isBlank` → `text(i).isEmpty`（**含空格的行 = 普通段落**，空格有宽度、光标跟着走） |
| **N2** | ① 删 `$f^{\prime}$` 后光标到第三行；② `a⏎⏎b⏎⏎c⏎⏎` 删 c 下跳一整行（中间行与 1 个尾换行都正常） | ① `reclaimEmptiedMath` 回收整段后 `caret = openStart`，而新缓冲区里那一行已经是**下一行**（实测竖条 175.8，公式在 133.8）；② `_normalizeEmptyParagraph` 的 `atEnd = nl2 + 1 >= out.length` 在"末行后还有空行"时判不出文末 ⇒ 文末那条"退一格"不执行 | ① 回收后若"删除区后面只剩换行"⇒ 光标退一格；② `atEnd = runTo >= out.length` |

## 三、N3c：撤回之后又装回来了（第二版判据）

实测（`$$\n\frac{a-x}{a+x}\n$$`，用竖条高度当"层"的证据）：

| 位点 | 竖条 (y, h) |
|---|---|
| 分子 `a` 之后 | 131.8, 21.0 |
| 分子末 | 135.1, 17.6 |
| **分母末尾** | **162.4**, 17.6 |
| **tex 末尾（`}` 之后）** | 改前 **159.0** → 改后 **148.5** |
| 块后（`$$` 之后） | 145.2, 20.0 |

⇒ 改前差 **13.8px**（tex 末尾贴到分母），改后差 **3.3px**。

**决策链**（临时 `ROWDBG` 输出，已删）：`at.dy=25.2` ⇒ `containing` = **分母字形行（20.0..45.0）**。
因为分式的根行里**一个字形都没有**（`\frac` 不产生 ¶ 盒），而分母行的**盒底恰好等于根行盒底** ⇒
"行盒底对齐"把分母认成本层。

**第一版（撤回）**：主行位点时无条件改用"这一层自己的行盒" ⇒ 差收到 3.27px，
但 `caret_layer_test` 全域扫描（10 类结构 × 67 位点）在 `\overline{AB}` 首尾两格报反例。

**第二版（现行）**：判据 = **上下堆叠**——"≥2 条内层行，且一条贴根行上缘、一条贴根行下缘"。
渲染树证据：

| 结构 | 内层行 | 是否堆叠 |
|---|---|---|
| `\frac{a-x}{a+x}` | 分子 `0..13.3` + 分母 `27.3..40.6` | ✅ 一贴顶一贴底 |
| `\sqrt{x+1}` | 只有被开方数 `2.9..14.5` | ❌ 单行 |
| `\overline{AB}` | 只有 `AB` 行 `2.6..13.5`（贴底、不贴顶） | ❌ 单行 |
| `\underbrace{AB}_{n}` | 不满足"一贴顶一贴底" | ❌ |

⇒ 四种结构的 tex 末尾实测（块后作参照）：`frac 148.5 / 145.2` · `sqrt 137.6 / 137.5` ·
`overline 140.3 / 136.9` · `underbrace 137.1 / 133.7` —— 都没有被拉平，只有分式走新路。

**守卫**：`test/render/caret_stacked_row_band_test.dart`（2 条：分式差值 ≤4px；`\overline`/`\sqrt`
的竖条不许被压扁 h>12）+ 既有 `caret_layer_test` 全域 67 位点全绿。**改前红**：① 实测 13.82px。

## 五、手验清单（给用户）

1. `甲⏎⏎⏎乙` 的空行里打几个空格 ⇒ 竖条还在、跟着右移。
2. 新建 → `w` → ⌫ → 打 `a` ⇒ `a` 在**第一行**（不再凭空多一行）。
3. `a⏎⏎b⏎⏎c⏎⏎` 删 `c` ⇒ 光标留在 `c` 那一行（不再下跳）。
4. 分式所在那一行末尾按 Enter ⇒ 只下一行、只多一行。
