## 二、A1：为什么这 3 行成了行内

### 1. 载荷原文（DeepSeek 抄写稿，逐字；**一个 `$` 都没有**）

```text
1. 证明： \forall \varepsilon > 0, \exists \delta = \varepsilon^2
\forall x_0 > 0, \forall x > 0 满足 |x-x_0| < \delta 时

|\sin\sqrt{x} - \sin\sqrt{x_0}| 

= 2\left| \cos\frac{\sqrt{x}+\sqrt{x_0}}{2} \sin\frac{\sqrt{x}-\sqrt{x_0}}{2} \right| 

\le 2\left| \sin\frac{\sqrt{x}-\sqrt{x_0}}{2} \right| 

\le |\sqrt{x} - \sqrt{x_0}| 

= \frac{|x-x_0|}{\sqrt{x}+\sqrt{x_0}} 

而 \sqrt{x}+\sqrt{x_0} > |\sqrt{x}-\sqrt{x_0}| \ge 0
（其余见用户原消息）
```

**这是整个 A1 的关键**：载荷是**裸 LaTeX**（网页版 copy 出来不带定界符），所以“行内还是行间”
**不是**我们改写的，而是 `smart_wrap`（`app/lib/lang/smart_wrap.dart`）**当场判**出来的。

### 2. 判据（`smart_wrap.dart:494-530`）

```dart
// ④ 行间块升级：整行只有这一个式子 且 含"显示倾向"的证据 ⇒ $$…$$
display: wholeLine && _wantsDisplayBlock(段)
```

`_wantsDisplayBlock` 只认两类证据：
- 命令命中 `_kDisplayCommands`（`sum/prod/int/frac/dfrac/lim/left/…`，**共 20 个**）
- 字面运算符命中 `= < > ≤ ≥ ≈ → ⇒`

### 3. 逐行验算（与 `…编辑.md` 对照）

| 载荷行（片段） | `wholeLine` | 命中证据 | 落地 | `…编辑.md` 实际 | 判定 |
|---|---|---|---|---|---|
| `证明： \forall …= \varepsilon^2` | ✗（`证明：` 前缀） | `=` | 行内 | `证明： $\forall…$` | ✅ 符合 |
| `\forall x_0 > 0 … \delta 时` | ✗（`时` 收尾） | `>` | 行内 ×2 | `$…$ 满足 $…$ 时` | ✅ 符合 |
| **`|\sin\sqrt{x} - \sin\sqrt{x_0}|`** | ✓ | **无**（`\sin`/`\sqrt` 不在表内） | **行内** | `$…$` | ❌ **用户要行间** |
| `= 2\left| \cos\frac…\right|` | ✓ | `=`+`\left`+`\frac` | 行间 | `$$…$$` | ✅ |
| `\le 2\left| \sin\frac…\right|` | ✓ | `\left`+`\frac` | 行间 | `$$…$$` | ✅ |
| **`\le |\sqrt{x} - \sqrt{x_0}|`** | ✓ | **无**（表里只有字面 `≤`，**没有 `\le`**） | **行内** | `$…$` | ❌ **用户要行间** |
| `= \frac{…}{…}` | ✓ | `=`+`\frac` | 行间 | `$$…$$` | ✅ |
| **`而 \sqrt{x}+… \ge 0`** | ✗（`而 ` 前缀） | `>` | **行内** | `而 $…$` | ❌ **用户要行间** |
| `(\sqrt{x}+\sqrt{x_0})^2 > |x-x_0| \ge 0` | ✓ | `>` | 行间 | `$$…$$` | ✅ |
| `\frac{…} < … = \varepsilon` | ✓ | `<`+`=` | 行间 | `$$…$$` | ✅ |
| `|\sin\sqrt{x} - \sin\sqrt{x_0}| < \varepsilon` | ✓ | `<` | 行间 | `$$…$$` | ✅ |

⇒ **`…编辑.md` 与 `…修订.md` 的差异只有 3 行**（`git diff --no-index -U0` 实测），
这 3 行**正好就是上表里三处"✗"**，且每一处都能由判据算出来、没有随机性。

### 4. 三个判据缺口

| 缺口 | 说明 | 性质 |
|---|---|---|
| **①** | `\le \ge \ne \to \Rightarrow \approx \equiv \sim` 这些**用命令写的关系符**既不在 `_kDisplayCommands`、也不在字面运算符表里 ⇒ `≤ |x|` 会判行间、而写法等价的 `\le |x|` 判行内。**同一语义两种待遇** | **真 bug**，直接补 |
| **②** | 整行只有一个式子、但**没有关系符/大算符**（`|\sin\sqrt{x}-\sin\sqrt{x_0}|`）⇒ 现在判行内。要不要按「这一行在源文里**自成一段**（上下是空行/文首/文末）」升格为行间？ | **与已拍板口径冲突**：`test/lang/smart_wrap_test.dart:85` 明确钉了「整行只有一个裸符号（`a_n`，无显示证据）⇒ 行内」（2026-10-17 B' 用户拍板）⇒ **必须用户重新拍板** |
| **③** | `而 <式子>`（同一行有引导词）⇒ `wholeLine` 天然为假 ⇒ 只能判行内 | **判不出来**，只能靠「可纠正」 |

## 三、A2：行内 → 行间 粘贴的决策矩阵（探针实测）

探针 `app/test/_probe_20261026_test.dart`（**调查完已删除**）直接跑 `decidePaste`
（`app/lib/lang/paste_context.dart`）：

| 载荷 | 粘进行间块 | 粘进行内公式 |
|---|---|---|
| 单行 `$\frac{a}{b}$`（复制公式内部得到的自洽片段） | ✅ `mathTex`（剥定界符后插入） | ✅ `mathTex` |
| **单行「文字 + 公式」混排**（`令 $x=1$ 时`） | ⚠️ **`pushOut`「已放到公式之后」** | ⚠️ `pushOut` |
| 单行纯文字（`一段中文`） | ⚠️ `mathTex` —— **中文会被直接插进 tex** | ⚠️ 同上 |
| 多行（`$$\ny=2\n$$` 或两行文本） | `replaceBlock`「已把这一整块换成粘贴内容」 | `promoteBlock`「作为行间块放到本行之后」 |

**由此有两个候选解释**（需要一次精确复现才能定，见 §七 Q2）：
- 若用户复制的是**含公式的混合文段** ⇒ 现状**设计上**就是「推出去」，不是坏了；
- 若用户复制的是**单行公式片段** ⇒ 现状应该能粘（除非落点不在公式内部，例如光标停在围栏行/块边界 ⇒ `mathRegionAt` 返回 `null`，走的是"文字流"那条路 ⇒ 结果是把 `$…$` 当文本插）。

## 四、B1：标题 + 分页 ⇒ 标题属性丢失

探针 A 实测（`planBlockOp(doc, caret, BlockOp.pagebreak)`，`doc = '上一段\n### T2\n正文'`）：

```text
caret=行首+0  |### T2        ← 正确：标题整个到下一页
caret=行首+1  |#
              |<!-- pagebreak -->
              |## T2        ← 标题级别从 3 变成 2
caret=行首+3  |###
              |<!-- pagebreak -->
              | T2          ← `###` 后面没空格 ⇒ 不是标题，正文
caret=行首+4  |###           ← ★ 用户这一例：前一页留一个空标题
              |<!-- pagebreak -->
              |T2           ← 正文（"变回正文了"）
caret=行首+5  |### T
              |<!-- pagebreak -->
              |2             ← 标题只剩 "T"，正文剩 "2"
caret=行首+6  |### T2
              |<!-- pagebreak -->
              |              ← 正确
```

**根因**：分页符的载荷是 `\n<!-- pagebreak -->\n`（`block_ops.dart:262`），
经 `insert_guard.planInsert` **原样插在光标处** ⇒ 落点在一行内部就把这一行**劈开**。
`insert_guard` 现有的 ③④⑤⑥ 只保护「围栏行 / 整行语法作载荷边缘 / `$` 粘连 / 分页符行」，
**没有保护"行首标记与它的内容不许被劈开"**。

**为什么用户会落在 +4**：`### ` 在渲染里**不可见**（一像素一语义的反面：零像素的标记），
用户"点到标题文字最前面"就是 `### ` 之后那一格。

**影响面**（比用户报的大）：`- ` 列表、`> ` 引用、`1. ` 有序列表同样会被劈开，
后半段当场失去块属性；`### T|2` 这种还会把标题与正文都改坏。

## 五、C1：安装为什么"先失败、两次 UAC"

### 1. 现状脚本（`scripts/pack_msix.ps1:198-240` 生成的 `双击我安装数语引擎.cmd`）

```bat
certutil -user -addstore -f Root          "%HERE%证书-数语引擎.cer" >nul 2>&1
certutil -user -addstore -f TrustedPeople "%HERE%证书-数语引擎.cer" >nul 2>&1
powershell -NoProfile -Command "Add-AppxPackage -Path '%HERE%数语引擎.msix' …"   ← 第一次装（多半失败）
if not errorlevel 1 goto ok
powershell … Start-Process certutil -Verb RunAs … Root            ← UAC 第 1 次
powershell … Start-Process certutil -Verb RunAs … TrustedPeople   ← UAC 第 2 次
powershell … Add-AppxPackage …                                    ← 重试成功
```

### 2. 根因

| # | 事实 | 证据 |
|---|---|---|
| ① | **当前用户存储对 MSIX 校验收效为 0** —— 包校验发生在 `AppXSVC`（系统服务、SYSTEM 上下文），只认**本机**存储 | 本机实测存储矩阵：`CurrentUser\Root` 有 · `CurrentUser\TrustedPeople` 有 · `LocalMachine\Root` **无** · `LocalMachine\TrustedPeople` **有**；本机装 MSIX（1.1.0.0）却能成功 ⇒ 起作用的只有**本机 TrustedPeople**，本机 Root 不是必需 |
| ② | 提升分支是**两条**独立的 `Start-Process -Verb RunAs` | 脚本 222/223 行 ⇒ 用户看到**两次 UAC** |
| ③ | 先装、失败后再提升 | 脚本 216 行 ⇒ 每个新用户都**必然**先看到一次 `0x800B0109` 大段报错（同学那张截图）|
| ④ | 两次 `certutil -user -addstore` 的失败被 `>nul 2>&1` 吞掉 | 所以第 ① 步"看起来做了"，其实对装包没用 |

⇒ 用户描述的「先报错 → 重试 → 弹 UAC → 成功（UAC 弹两次）」**与脚本逐行对应**，不是随机现象。

### 3. 建议改法（待拍板，见 §七 Q4）

```bat
① 先用一条命令查【本机 TrustedPeople】有没有这把证书（certutil -store -machine TrustedPeople <thumb>）
   · 有  ⇒ 跳过全部证书动作（老用户重装/升级：**零 UAC**）
   · 没有 ⇒ 弹**一次** UAC，在同一提升进程里把【本机 Root + TrustedPeople】都装上
② 装包（只装一次：不再有"先失败一次"）
③ 失败才打印失败信息（保留"改用绿色版"的兜底），不再打两遍 PowerShell 报错
```
