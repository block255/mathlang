## 六、环境事实与踩坑（下次别再踩）

1. **受限沙箱下 flutter / dart 的任何命令都会失败**（`CreateFile failed 5` / `ProcessException: 拒绝访问`）——它们用**管道**拉起子进程（git / analysis_server / gradle）。环境变量重定向是**必要不充分**条件；`dart analyze` 同样受影响。
   → 结论：**开发本项目的会话需要完整访问权限**（用户已知悉；约定：把需要放行的命令**攒到阶段节点一起跑**，日常靠热重载推进）。
2. **包入口文件名 ≠ 包名**：必须写 `import 'package:flutter_math_fork/flutter_math.dart';`（写成 `flutter_math_fork.dart` 会让 `Math`/`SelectableMath`/`MathStyle` 全报未定义）。
3. `dart` CLI 遥测路径写死 `%APPDATA%\.dart-tool\`，`FLUTTER_SUPPRESS_ANALYTICS` 对它无效（把 `APPDATA` 重定向进工作区可绕过，但分析仍会被管道挡住）。
4. 工作区根带 **低完整性标签 + 沙箱授权项**（`Low Mandatory Level:(OI)(CI)(NW)` / `S-1-4-*`），故 VS 装在**工作区之外**（`D:\Visual_Studio`）。
5. **后台任务不跨轮次**：热重载桥作为"后台任务"启动会在轮次结束后被回收 → 开发服务已停。下次用**脱离进程**方式启动（`Start-Process ... -WindowStyle Hidden`）。
   ⚠️ **2026-10-14 复核**：该方式**只在本机不关机期间有效** —— 次日上午回来时 57134 / 57136 均已无监听（机器重启或会话清理），**所以每次开工仍要重拉一次**，别指望它真常驻。

## 十、两条必须遵守的操作纪律（都是踩坑换来的）

1. ★ **语义树一开，CDP 坐标点击就失效**（Flutter 语义 DOM 覆盖层把点击退化成"点元素中心"）。解决：先 `document.querySelector('flt-semantics-placeholder').click()`，再注入
   `flt-semantics, flt-semantics-container, flt-semantics-host { pointer-events: none !important; }`
   → **可读 + 可点**。热重启后语义树需重新启用。
2. ★ **release 基准必须先预热再取数**，第一轮数据先用内部自洽性筛一遍（本次第一轮出现 `100行纯文字=9320ms` 的假数据；复测即正常）。另：**工具栏 `Wrap` 会因状态栏文字变长而重排** → 每次点击前重新取坐标。
