## 四、下一批：**选择边界与剪贴板**（原 R-甲3，已升格）——讨论结论

### 4.1 现场（用户 2026-11-01 23:5x 原样；第三条是探针复现）

```tex
$x]{a_{1}}+……+\sqrt[x]{a_{2020}}$          ← `\sqrt[` 丢了
${\sqrt[x]{a_{1}}+……+\sqrt[x]{a_{2020}}}{2020}$  ← `\frac` 丢了
$x+y=1\\x-y=3\end{cases}$                    ← 孤立 `\end`（探针复现，不在用户原帖里）
```

### 4.2 根因（2026-11-02 探针，正文见 R甲调查 §四）

`lang/clipboard_slice.dart` 的三条规则只覆盖**终点侧**与"词中间"：

| 规则 | 漏的地方 |
|---|---|
| ③ 控制词吸附 | 只处理切在**词中间**；切在**命令之后（参数 `{` 上）不吸附** |
| ② 括号配平 | 只数 `{}`；把起点平衡到**参数的 `{`**，把命令留在外面；`[...]` 完全不参与 |
| 参数补全 | 只在片段**以 `\` 开头**时才补 ⇒ 起点在参数里永不触发 |
| 环境 | 只补"片段自己打开的 `\begin`"；起点在环境内部 ⇒ 孤立 `\end`（注释写"台账登记"，台账里没有） |

- **与 `5cf11fd` 无关**：未合并的原句就能复现。
- **真正让它可达的是 `91d8aa0`**（拖选端点第一次能精确落进结构内部）。
- 守卫缺口：`clipboard_slice_test` 的"全域"只断言 **`$` 个数是偶数**（`{...}{...}` 花括号平、`$` 也偶 ⇒ 全绿）。
