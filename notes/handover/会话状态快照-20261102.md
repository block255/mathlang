## 三、清晰基准（讨论定稿）

> **完整版在 [`../dev_log/2026-11-02接缝与括号.md`](../dev_log/2026-11-02接缝与括号.md) §七**，
> 规格在 S4 §10。这里只放一句话版：

1. **三种形状**：A 括号全正文（升格）· B 括号全数学（并回原段）· **C 跨围栏 → 输入层禁止**。
2. **判据**：恰好一整段 `$…$` ⇒ 内联；纯正文 ⇒ 整对升格；混着/两段/空段 ⇒ 不升格（字面）。
3. **括号保真**：`[]` `{}`（转义 `\{\}`）`（）［］｛｝`；**空白 → `\ `**；**中文允许进数学**；不生成 `\text{}`。
4. **接缝乙**：相邻行内公式合并围栏（零新增字符）；文字邻居直接插；不补换行/空格/`$$`。
5. **输入层同层**：打闭合括号时落到开括号层；只认紧贴公式边界；夹文字/行间不动。
6. **守卫口径**：计划层 ≠ 落盘层，必须**端到端**；改前红；全域断言（无 `\n`/`$$`、种类不变、一步撤销）。

## 四、下一批：**复制残片**（R-甲3）——回顾

### 4.1 现场（用户 2026-11-01 23:5x 原样）

```tex
$x]{a_{1}}+……+\sqrt[x]{a_{2020}}$          ← `\sqrt[` 丢了
${\sqrt[x]{a_{1}}+……+\sqrt[x]{a_{2020}}}{2020}$  ← `\frac` 丢了
$x+y=1\\x-y=3\end{cases}$                    ← 孤立 `\end`
```

### 4.2 根因（2026-11-02 探针，正文见 R甲调查 §四）

`lang/clipboard_slice.dart` 的三条规则只覆盖**终点侧**与"词中间"：

| 规则 | 漏的地方 |
|---|---|
| ③ 控制词吸附 | 只处理切在**词中间**；切在**命令之后（参数 `{` 上）不吸附** |
| ② 括号配平 | 只数 `{}`；把起点平衡到**参数的 `{`**，把命令留在外面；`[...]` 完全不参与 |
| 参数补全 | 只在片段**以 `\` 开头**时才补 ⇒ 起点在参数里永不触发 |
| 环境 | 只补"片段自己打开的 `\begin`"；起点在环境内部 ⇒ 孤立 `\end`（注释写"台账登记"，台账里没有） |

- **与 `5cf11fd` 无关**：未合并的原句就能复现。
- **真正让它可达的是 `91d8aa0`**（拖选端点第一次能精确落进结构内部）。
- 守卫缺口：`clipboard_slice_test` 的"全域"只断言 **`$` 个数是偶数**（`{...}{...}` 花括号平、`$` 也偶 ⇒ 全绿）。

### 4.3 修法候选（**未拍板**）

| 案 | 做法 | 评价 |
|---|---|---|
| **甲（推荐）** | **起点侧吸附**：起点落在命令参数 / 可选参数 `[...]` / 环境内部 ⇒ 向前扩到命令首（`\frac` / `\sqrt` / `\begin`）；`[...]` 参与配平；`_completeEnvs` 补起点侧 | 最小、可纯函数测；覆盖三类形状 |
| 乙 | **扩到"最小包住整个选区的结构节点"**（参数组 / 可选参数 / 命令 / 环境） | 更通用（跨参数也能整段取），但需要结构节点表；改动更大 |
| 丙 | 只补 `\frac` / `\sqrt` 两种形状 | 不够：`\begin…\end` 是同一类 |

> 推荐 **甲** 起步；若做乙，先探针 `caret_sites` 的槽区间能否直接当"结构节点表"。
> **守卫升级**（两案都要）：把"`$` 偶数"换成**结构完整性**全域断言
> （每个 (i,j)：无孤立 `\end`、每个 `\frac`/`\sqrt` 参数齐、片段不以 `}`/`]` 开头）。

### 4.4 需要拍板的点

1. 修法选 **甲** 还是 **乙**？
2. 环境起点侧是否同批做（`\begin…\end` 用户现场没直接踩，但探针能复现）？
