## 五、本轮确立的铁律（讨论出来的，不是猜的）

1. **行 = 段**（视觉行 = 一个段）；段内软换行不产生行；`Shift+Enter` = 段内硬换行。
2. **空行 = 空段 = 一行**；空行的行高与文字行**同一把尺子**。
3. **行盒 / 行间距 / 段间距**三个量必须分开：相邻两段行顶间距 = 行盒 + 段间距。
4. **文末与分页原页都有"永久空行"**承接光标，两处不因"末页/原页"而不同。
5. **Enter 次数 = 退格次数不作为定理**，它是其余都对时的自然结果。
6. 分页符在存储里是**单独一行**（`<!-- pagebreak -->`）、渲染零像素、不可见；只说"**分页符行的行首**"，不说"分页符内"。
