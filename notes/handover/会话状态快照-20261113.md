## 一、三条反馈的根因

| # | 现象 | 根因 |
|---|---|---|
| ① | 半边 `\left|…\right|` 被允许选中 ⇒ 复制出来 `[公式不完整]` | **`\left/\right` 在 §3.1 壳表里，但实现一行没做**（`isCompleteFragment` 不认、`requiredArgs` 也没有）。点竖线的落点天然在内容起点 ⇒ 拖选极易丢掉开头那个 `\left|` |
| ② | 跨行间块拖选复制 ⇒ 粘到哪儿都爆源码 | 行间段内容自带首尾换行，复制仍用单个 `$` 包 ⇒ `$⏎…⏎$`（不是任何合法结构）；块间 `\n` 原样抄；**R5「整块带 `$$`」从没实现** |
| ③ | 拖选分数线（`}{`）打 x ⇒ 公式坏（有时还没红字） | 替换通道是**裸 `_buf.replace`**，不走 `planDelete`；且判据缺"命令参数齐"、"最小完整单位 = 对象"没实现 ⇒ `}{` 不扩、`\frac{` 又直接落"整段" |

## 二、本批改了什么

**Lib**
- `lang/tex_structure.dart`：`\left/\right/\middle` 定界符栈（壳表那两行）；**命令参数齐**（`_hasArgsAhead`）；
  `expandDelimiterPairs`（切开就扩到整对）；`delimiterPairAt` / `delimiterTokenAt` / `delimiterTokenEndingAt`。
- `lang/clipboard_slice.dart`：行间段载荷规则（`_displayPayload`：单块 = 单行片段、跨块 = `$$` 块 + 片段）；
  段内片段也走 `_completeWithin`（不再因为"是块"跳过对象补齐）。
- `lang/delete_range.dart`：删除前先扩定界符对；`_objectExpandOnce`（**扩到对象**：主人命令 / 命令全部参数）；
  `_spanRemainderComplete` 自动继承新判据。
- `lang/paste_context.dart`：新增 `PasteApply.blocks`（跨块 ⇒ 按块落到行后）；**单块进行内 ⇒ 剥围栏 + 压换行 ⇒ 行内 tex**

- `render/selection_range.dart`：三击行间块 = **可见内容**（去 `$$` 与首尾空行）；

- `test/lang/shell_pair_test.dart` · `clipboard_block_payload_test.dart` · `delete_object_expand_test.dart` · `paste_block_test.dart`

## 三、新定的口径（改行为，防后人翻旧账）

1. **`\frac{bxc}+d` 算"不完整"**：KaTeX 不报错，但 `+` 被吃成分母 —— 静默错位也算坏。
   判据 = 命令的必需参数必须是**花括号组**（外来裸参数 `\frac12` 会被判不完整；`test_data` 实测 0 处）。
2. **单块复制 = 片段**（单行 `$…$`）；**只有跨 2+ 个块**才出 `$$…$$`。R5/决定4 改判（旧句"整块也带 `$$`"从未实现）。
3. **三击行间块 = 可见内容**（围栏不参与选区）；10-19 的"含围栏"作废。
4. **替换 = 替换整个对象**：切开结构 ⇒ 扩到最小完整单位（双击粒度）再插；一次 `replace` = 一步撤销。
5. **双击半边定界符 ⇒ 整对**（`\left|` / `\right|` 不是独立可替换对象）。
