## 七、追加（同日 · 第二批量）：**段间距不承接字符**

> 用户在装机版上手测发现两件事：① Enter 换段之后，"两段之间的**段间距**竟然能当一个容器行
> 把光标放进去"；② `Shift+Enter` 在**行首/行尾**的观感和 `Enter` 一样，而且敲字之后
> 字落在"上一行的同段下一行"。

### 1. 实测（探针，逐偏移扫光标 y；`A` 行顶 = 95.6）

```
A⏎      {2:137.4}                              文末：2 行，每个格子都是 38.4
A⏎⏎     {2:137.4} {3:175.8}
A⏎⏎B⏎   {2:126.2} {3:137.2} {4:137.2} {5:175.6}   ← 126.2 是幽灵
A⏎⏎⏎B⏎  {2:126.2} {3:137.4} {4:175.6} {5:175.6} {6:214.0}
A⏎B⏎     {2:126.0} {3:126.0} {4:164.4}            段内软换行：没有幽灵
```

`126.2 = 95.6 + 27.2 + 3.4` = **上一行行盒底 + 光标内缩**，而下一段在 **133.8** —— 差 11.2 = 段距。
所以那一格不是"段距里随便一点"，它**精确等于"如果这里有字，字应该在的高度"**。

### 2. 结论（用户拍板）

- **段间距从设计上就不承接字符**（原话「不然基本单位就很容易错乱」）。
- `Shift+Enter` 只在**光标两侧都有字**时成立；行首/行尾**等价 Enter**（用户已补进只读基准 6）。
- 点段距 ⇒ 落**下一段行首**（段距是 `leadingGap`，挂在下一段、页首丢弃）。

### 4. 教训（第 5 条）

**不许用实现迁就一条错的断言。** 2026-10-26 我立的全域守卫写的是
「每个**偏移**至少有一根光标」—— 那条命题本身就是错的：分隔符零高度、没有行盒，
而"每个偏移都必须有"逼着渲染层给它编一个 y（只能画进段距）⇒ 造出了用户看到的那一幕。
**命题改成「每个视觉行一个光标 + 分隔符那一格一根都不许有」之后，同一个现象就自然消失了。**

| 把中间那一段的字删光 ⇒ **多出一个空行** | md 里两段之间本来就存着 `⏎⏎`（段界）。删空那段 ⇒ 左右两个段界**并置**成 `⏎⏎⏎⏎`；版面口径是"第一个空行是段界(0 高)、之后每多一个 `⏎` 算一行" ⇒ **2 行**，而空段落只有 **1 行** |
| 文末最后一行的行尾删光 ⇒ **光标掉到下一行** | 同一处：末尾换行串多一格，把光标顶到"文末下一行" |
| 标题删光内容后再退格 ⇒ **爆出一个 `#`** | `_headingRe = ^ {0,3}(#{1,6}) +` **要求 `#` 后必须有空格**；删掉那个空格 ⇒ 块降级 ⇒ `#` 漏成正文 |

### 2. 改了什么（都在 `render/math_nav.dart` 的删除层）

- 新增 `_visibleObjectDelete(source, at, caret)`，由 `_textLayerDelete` 调用：
  ① **分隔线 `---`** 是整行对象（整行连换行去掉，不留 `--`）；
  ② **行首标记**（`# ` / `- ` / `> `，判据复用 `BlockMarkers.markerLength`）删到内部 ⇒
     **整块降级**（标记一起去掉、内容保留、一步撤销）；
  ③ **普通字符** ⇒ 删掉它，并做**空段落归一化**：如果这一行因此变空、且左右段界并置
     ⇒ 把多余的那格换行**一起收掉**（文首同样收；文末收末尾那格，光标退一格，
     否则会站在"文末下一行"上看起来掉了一行）。
- 一次删除 = **一个 `SmartEdit`** ⇒ 撤销一步（`edit_view._applyEdit` 一个事务）。
- **渲染口径一个字都没改**（`extraBlankHeight` 还是 `(n−1)×行高`）⇒ Enter 那条路（基准 2/3）零风险。

### 3. 证据

- 守卫 `test/editor/delete_empties_paragraph_test.dart`：**先红 8 条**（现象全部复现）→ 全绿；
  13 条，其中 2 条是**版面层**（真 `EditView` 渲染，断言光标 y 前后相同）。
- `flutter analyze` 零告警；全量 **1764 通过 / 0 失败**。

### 4. 一个必须记住的教训（本轮最大的坑）

**`DocBuffer.deleteBackward()` 是死路径** —— 界面走的是
`edit_view.dart:1085 → smartEditAt(...)`，`lib/` 里**没有任何一处**调 `deleteBackward/deleteForward`。
第一版守卫就是用 `deleteBackward` 写的（还据此得出"删除侧零保护"的错误结论）——
**测了用户永远走不到的路**。以后写删除/编辑类守卫，入口一律 `smartEditAt`。

顺带纠正一个事实：**`$` 围栏在删除侧是有保护的**（`_innerBoundaryDelete` 委托进公式内层边界、
空壳整段删、`_fenceBrokenByDelete` 三类坏法一律拒删、分页符 `_wouldLeaveBareMarker`）——
**不动，也不该动**。真正没保护的是 `# ` / `---` 这类行首标记（本批已补）。

## 十一、第十一批：检查更新去限频 + 图标自愈 + 卸载清理（1.2.9）

> 用户 2026-10-28 晚手测：①"自动弹窗一次都没出现" ②"更新后桌面图标变白纸"
> ③"暂不更新和忽略此版本应该分开"。

### 1. 三个真根因

| 现象 | 根因 |
|---|---|
| **自动弹窗从未出现** | `shouldAutoCheck(minInterval: 24h)` —— 装完新版启动查过一次（当时已是最新），几分钟后发了更高版本，用户再启动时**24h 内不再查** ⇒ 弹出条件根本没被执行。用户的判断（"一天开不了几次"）比我当初的限频前提正确。 |
| **桌面图标变白纸** | `IconLocation` 用的是 `Platform.resolvedExecutable` ⇒ **写死 `WindowsApps\..._<版本>_...` 目录**；且 `ensureDesktopShortcut()` 里 `if (文件存在) return;` **只建不修**。Windows 的**图标缓存**替它兜了很久，重启刷新缓存才露白。 |
| **两种"不更"混在一起** | `later` 同时承担"关弹窗"和"跳过版本"两种语义 ⇒ 名不副实。 |

### 2. 改法

- **A** `shouldAutoCheck({required bool enabled})` —— **连时间参数都删了**（想再塞回限频必须先改签名，守卫会红）；`updateLastCheckAt` 只用于显示。
- **E** `UpdateChoice` 拆成 `later`（什么都不记）/ `ignoreVersion`（写 `updateIgnoredVersion`）；四按钮 + 两行区别说明（写在按钮上方）。
- **B** 图标随包带 `assets/icon/app.ico`（256/64/48/32/16，由包内 `Square150x150Logo.scale-200.png` 生成）⇒ 启动时拷到 `%USERPROFILE%\mathlang\数语引擎.ico`（**稳定路径**）；快捷方式永远引用它；`ensureDesktopShortcut()` 改成**印戳（`shortcut.stamp` = 版本+图标字节数）校验，不一致就重写**。
- **C** 卸载 cmd：删桌面 `.lnk` + 开始菜单死链；`y` 才 `rmdir %USERPROFILE%\mathlang`。
- **D** 安装 cmd：删掉 10-18 手工留下的开始菜单死链（指向 `dist\v1.0.0`）；以后不再写开始菜单（MSIX 清单 `AppListEntry="default"` 自带）。

### 3. ★ 新验证手段：**探针钩子**（不发布就能验"启动自动弹窗"）

`update_gateway_native._apiUrl()`：**只在非打包版**读环境变量 `MATHLANG_UPDATE_API`
⇒ 可指到本地假 release（打包版永远走真地址，不留安全口子）。做法（3 分钟，下次照抄）：

```
1. 写假 release JSON（tag_name: v9.9.9 + 一个假 msix asset）
2. node 起本地服务器：createServer → 200 + 那段 JSON（绑 127.0.0.1:8765）
   ★ 别用 PowerShell 的 HttpListener —— 非提升进程会因 URL ACL 起不来（实测）
3. 写 .cmd：set MATHLANG_UPDATE_API=http://127.0.0.1:8765/latest && start 数语引擎.exe
4. 双击 ⇒ 启动 3 秒后应自动弹「发现新版本 9.9.9」
   ⇒ 点「暂不更新」重开还弹；点「忽略此版本」重开不弹 = A/E 验收
5. 关服务器、删临时文件（探针不进生产代码）
```

★ **坑一**：`Start-Process mathlang.exe` 会让子进程占住命令的 stdout 管道把命令挂住
（实测卡 180 秒）⇒ 探针一律**让用户双击**，别自己拉 GUI。
★ **坑二**：`Stop-Process` 千万别按进程名批量杀 `node` / `powershell` —— DSH 本体就跑在
node 上，本次把 job runner 一起杀了（`Windows Job runner exited with exit code 4294967295`）。
要杀就**按端口找 PID**。
