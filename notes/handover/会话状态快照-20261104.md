## 三、这一轮定下来的口径（改行为的地方，防后人翻旧账）

| 口径 | 内容 | 取代了什么 |
|---|---|---|
| **空行 = 长度 0** | 含空格的行 = **普通段落**（空格有宽度、光标跟着走）。两处判据：`blank_runs.blankRunFrom` 与 **`block.LineIndex.isBlank`** | 旧的 `trim().isEmpty`（同一条事实曾有两处实现，导致"改了一处仍然没修好"） |
| **套娃判据** | **空槽才挡、有基座放行**（`scriptSlotHasBase`）；`insert_guard` 的"搬到对象之后"只在空槽触发 | 2026-10-30 的"同种脚本一律拒"（它把合法的 `x^{2^{}}` 一起挡死） |
| **行首 pad** | 文末空行行首插入（打字 / 面板 / 快捷键）**都要补** `\n`；**文首不补** | "pad 是缺陷"这个错判（实测补了才对齐：dy −0.2 vs −38.6） |
| **删除落点** | 删完光标落在**被删那一行**（`reclaim` 在"后面只剩换行"时退一格；`_normalizeEmptyParagraph` 的 `atEnd = runTo >= out.length`） | "删完落到下一行"（+38.6px，只在"末行后已有空行"时出现） |
| **Enter 落点** | **行内公式 tex 末尾**与行间块末尾同待遇：出到公式之后 **+1 行** | `c != le ⇒ \n\n`（一按两行） |
| **P3b 撤案** | `setCaret` 出口**不加**断言 | "setCaret 是唯一出口"这个未验证的前提（全量红 15+ 条，红的是**故意**把光标摆到分隔符上验证"那格不画竖条"的守卫） |
| **主行带判据** | 主行位点在"这一层量不到字形"时，**只有"上下堆叠"的结构**（≥2 条内层行、一条贴根行上缘、一条贴下缘，如分式）才用根行盒；`\sqrt` / `\overline` / `\underbrace` 保持老路 | 第一版"无条件用根行盒"（在 `\overline{AB}` 上被全域扫描判死） |
| **单行段的判据** | 不许用"段盒高 > 1.6em"猜"多行"。行内放分式/根号/矩阵时一行也会很高（≈2.05em）。现行：`≤ 2.5em` **或** "公式占段高 ≥70%" | 1.6em 那版（16px 擦边过、18px 判错 ⇒ 竖条去画分母） |
| **默认值 ≠ 用户配置** | 几何/手感类守卫必须在**多档字号**下跑（矩阵 `caret_band_matrix_test`：14/16/18/20/24；`caret_line_center_test`：16/18）。矩阵里**只写不变式**，不写死数字 | "只在 16px 默认值下绿"的那套守卫 |
