## 0. 工具链结论（★ 下次直接用，别再摸索）

| 项 | 结论 |
|---|---|
| UIA（电脑操作插件） | 调试版**也没有**语义树：`computer_find` / UIA RawView 都只有 `数语引擎 / FLUTTERVIEW / 标题栏三个按钮`（`ensureSemantics` 已开，但 Win 端 AX 桥没把这些节点发布给 UIA）。⇒ **不要指望 `pattern invoke`** |
| 读界面（推荐） | **VM Service HTTP**：`ext.flutter.debugDumpSemanticsTreeInTraversalOrder` 取**完整语义树**（label / tooltip / flags / 矩形）。VM 地址在 `scripts\state.json` 的 `vmService` |
| ★ 坐标 | 语义树里每个节点的 `Rect` 是**相对父节点**的 ⇒ 必须**沿祖先累加**才是屏幕坐标（`_cache\ctl.ps1` 已实现，输出 `c(x,y)` 就是中心点） |
| 点按钮（推荐） | `PostMessage(FLUTTERVIEW, WM_LBUTTONDOWN/UP)`。★ **lParam 用逻辑像素（不要乘 DPR）** —— 实测乘 1.5 会点到右边去（窗口是 DPI 虚拟化的） |
| 按键 | `WM_KEYDOWN/WM_KEYUP` 有效（Escape 能关菜单、`combo 17,90` 能发 Ctrl+Z） |
| ★ 读文档文本 | 直接读 `app\build\windows\x64\runner\Debug\mathlang-session.json`（**`Get-Content -Encoding UTF8`**，否则中文变成乱码导致 JSON 解析失败）——比截图/语义树精确得多 |
| 截图 | `computer_see target=window` |
| 脚本 | `_cache\ctl.ps1 -Op dump\|click\|key\|combo\|down\|up -X -Y -Vk -Keys "17,90"`（**源文件必须纯 ASCII**） |

★ 踩坑：用 `Set-Content` 往返改 `.ps1` 会把中文读成 ANSI 写坏（有一次把注释和下一行**粘成一行**，`$ci` 永远不执行、查了半天）⇒ 脚本里**不写中文字面量**（正则用 `\u5b57\u7b26` 这种转义）。

### 1.3 发现（待讨论修法）

| 编号 | 现象 | 根因 | 证据 |
|---|---|---|---|
| **F1** | 光标在**行间公式块内部**时，「块类型 → 标题 1」照样执行 ⇒ `# ` 插进公式源码 ⇒ 页面出现红字 `[公式不完整]`，公式散架 | 只挡了「整行是 `$$` 的围栏行」，**没挡围栏内部的行** ⇒ `planLineMarkerSet` 需要认"光标是否落在某个 `$$…$$` 块内" | 文档文本实测：`$$\n# \n$$`；截图 `TA1-F1-broken` |
| **F2** | 新建后状态栏「0 字符 · **2 次编辑**」 | `EditView._edits` 只在**换 buffer 实例**时归零（`didUpdateWidget`），`newDocument()` 走 `_buf.loadDocument('')`（同一实例）⇒ 计数跨文档累积；打开文档同理 | 语义树状态栏读数 |
| **F3** | 合成 `Ctrl+Z` 没撤销（第二次反而 +2 字符） | **未定**：合成键的 lParam/扫描码是我瞎填的，可能没带 Ctrl 修饰 | ★ 要用**真键盘**对照，别拿假证据改代码 |
| **F4** | 导出菜单**太窄**（112 px），长项全部折成两行：`Markdown` / `(.md)`、`图片集（每页` / `PNG）`、`PDF（图片式` / `+ md 附件）` | `PopupMenuButton` 默认 `minWidth 112`，item 里的 `Text` 会软换行 | 截图 `TA1-export-menu` |
| **F7** | **分页符被污染后，原始编码 `<!-- pagebreak -->` 直接显示在正文里** | ① 插入分页后光标停在**标记行末**（实测 caret=19）⇒ 下一次插入（面板符号/公式）追加到同一行 ⇒ 该行不再是"整行正好是标记" ⇒ 渲染退回**普通段落**，把 HTML 注释当正文画出来 | 文档文本实测：`\n<!-- pagebreak -->$\frac{}{}$\n$$…`；截图 `TA1-display-block` |
