## 安装（两步）

1. 下载 **`mathlang-v1.1.0-win64-setup.zip`**，解压；
2. 双击 `数语引擎\双击我安装数语引擎.cmd` → 弹**一次**管理员授权（信任本软件的自签证书）→ 点「是」⇒ 自动安装并打开。

要不要安装版都可以：

| 想要 | 下哪个 |
|---|---|
| 一键装好、以后**不弹** SmartScreen | `mathlang-v1.1.0-win64-setup.zip`（解压后双击那个 cmd） |
| 绿色版、解压即用 | `mathlang-v1.1.0-win64-portable.zip`（**先双击 `启动数语引擎.cmd`** 装一次证书） |
| 直接装 MSIX | `mathlang-v1.1.0-x64.msix`（先信任包里的 `.cer`，再双击） |

## 这一版修了什么（自 v1.0.0 以来约 100 个提交，全是实测反馈）

**点击 / 光标**

- 修好「**一行里某几个字符点不进去**」：`\text{旁注：…}` 这类外来写法里的空格会把「盒 ↔ 原子」配对打乱，导致整块点击退化（点左边落到别处、点右边没反应，连带那块里的分式也点不到）；
- 修好「**极限的下限点不到**」：行内公式左缘 4px 命中带原来会抢走画在最左边的墨迹；
- 两个公式块紧贴时**不再同时出现两根光标**；块与块之间空一行时**空行让位**；
- 分界线（`---`）上下不再是「看不见光标」的死区；空标题 / 空引用块的光标与行高也修了（原来矮 7px，打字会跳）；
- 多行环境里点右侧留白**落到本行末尾**（不再是整块末尾）；`&=` 的等号不再被当成可填位点。

**删除**

- 退格 / 删除**不再把命令名劈开**（以前会造出 `\ext`、`\uad` 这种未定义命令，整块变「公式不完整」）；
- 删除**不再弄坏行间公式的围栏**（以前连按两下可能把两块粘成 `$$$$`，整段 LaTeX 裸奔）；
- `\left( … \right)` 少了配对时会**整对删**；环境里的 `&`、`\\` 这些结构记号不许被单删；
- `\text{…}` 里**删得干脆**：删掉最后一个字时连包装一起回收，不留空壳、也不会有"按了没反应"的一下。

**输入 / 粘贴 / 导入**

- 数学段里打**汉字**会在那里断开（汉字回到文本层，用正文字体）；
- 中括号 `[` `]` 也按断点处理：一个括号对不再被拆到两套字体里；
- 粘贴 AI 答案里**带环境**的裸 LaTeX 不再被 `&` 切成一堆「公式不完整」；
- 导入时的自动包裹更保守（幂等、不吞正文、不再造出行内 `$$`）；
- 行内分式放大到全尺寸（`\dfrac`），行内公式里的中文字重与正文一致。

## 三点说明

- **行间公式块不跨页** —— 真要跨页，请改用「多行公式 + 行内」的写法（这是设计取舍，不是 bug）；
- **导出的 PDF 是图片式** —— 正文能选中文字，但 PDF 里的文字不可搜索（文本式 PDF 还没做）；
- **只有 Windows 桌面版** —— 手机端在路线图里。
