## 这一版修的是"复制粘贴与替换"

三条都来自你日常写作业时的实测，共同点是：**以前只有"退格/Delete"那条路会照顾结构，复制和替换这两条路不会**。

### 1. 半边绝对值 / 半边括号，复制出来不再缺一半

从 `|…|` 里面起手拖选、拖到右边括号之外再复制，过去会得到
`f^{\prime}(\xi_1)\right|\le c\left|f(\xi_1)\right|` 这种**缺开头**的源码，粘回去就是 `[公式不完整]`。
现在复制 / 剪切 / 删除 / 替换在落地那一刻都会检查：只要切开了一对 `\left…\right`，
就自动补成整对。**双击那根竖线**也会直接选中整对（半边定界符不再是可替换对象）。

### 2. 行间块复制：单块能舒服地粘进行内，跨块保留为多个块

- **单个行间块**（哪怕围栏各占一行）⇒ 复制出来是**单行片段** `$…$`：
  粘贴到行内就是行内内容（`aligned` / 矩阵也照常渲染）；
- **跨 2 个以上块**拖选 ⇒ 完整覆盖的块仍是 `$$…$$`，按块顺序落到光标所在行之后，不会被合并成一块；
- **三击行间块** ⇒ 只选可见内容（不再把 `$$` 和首尾空行带进选区）。

### 3. 拖选半截结构再打字/粘贴 = 替换整个对象

过去拖选到一条分数线（源码里是分子与分母之间的 `}{`）、打一个字替换，
公式会**静默错位**（`+` 被吃成分母，还不报红字）；选中 `\frac{` 再打则会变成 `[公式不完整]`。
现在规则统一了：**切开结构就按"整个对象"替换**（整个分式、整个根号、整对环境），
一次替换仍然是一步撤销；只选分子里的一个字，还是只换那个字。
