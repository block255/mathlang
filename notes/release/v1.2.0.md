## 1.2.0 · 行与段的地基修好了 + 导出不再带白纸 + 检查更新

**这一版有一半的改动是"看不见的"** —— 它们只让编辑手感变对，界面几乎没变。

### 一、编辑手感（行 / 段 / 空行）

- **两段之间的段间距不再能放光标**。以前在段距里点一下，光标会悬在"两段之间的缝"里，
  敲字还会把下一段**并进来**；现在点段距 = 落**下一段行首**。
  根因：Markdown 的段落分隔符（两个换行里的第二个）**有语义、没像素**，不该有光标位置。
- **`Shift+Enter` 只在光标两侧都有文字时才是"段内换行"**；在行首/行尾按它**等价 Enter**
  （"段内空行"在 Markdown 里不存在 —— 空白行就是换段）。
- 文末下一行那个空行**永远在**、永远能承接光标（末页与分页原页同一套），
  `Enter` / `退格` 在文末**一下对一行**。

### 二、导出（PDF / 图片集）

- 文末留空行撑出来的**纯空行页不再进产物**（判据用"这一页有没有真实内容"，不看像素）。
- 屏幕上的页数**不变** —— 那几张白纸还在，你还能在上面点、在上面按 Enter。

### 三、检查更新（新）

- **启动后静默查一次**：没发现不打扰；失败也不弹窗，只在设置里留一行
  「上次检查失败：网络不可用」。
- 只有**发现新版本**才弹窗：**暂不更新 / 前往发布页 / 一键更新**，带
  「以后不再自动检查更新」勾选。勾上 = 完全不再自动查（手动按钮照旧可用）；
  不勾 + 暂不更新 = **只跳过这一个版本**。
- 装完弹「更新完成」：**立即重启 / 暂不重启**。
- 设置 → 关于 → 新增**更新**小节（检查更新 / 自动检查开关 / 发布页）。

### 四、安装与版本

- **安装只要一次 UAC**（以前是"先报错 → 重试 → 弹两次 UAC"）：脚本先查本机受信任存储里
  有没有这把证书 —— 有就**零 UAC**，没有才弹**一次**、在同一个提升进程里把 Root 与
  TrustedPeople 一起装上；证书装不上就**明确报错、不硬装**（不再先打一段 0x800B0109）。
- **「关于」页现在显示真版本**：以前它一直写死 `1.0.0`（比包版本慢两版多），
  现在由构建脚本从 `pubspec.yaml` 生成。

## 安装

下 `mathlang-v1.2.0-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。
已经装过 `1.1.x` 的**直接覆盖升级**，数据与设置都保留。

装不上就换绿色版 `mathlang-v1.2.0-win64-portable.zip`：解压 → 双击 `启动数语引擎.cmd`（解压即用）。
