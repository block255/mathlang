## 1.2.1 · 一键更新真正能用（改"外挂小助手"）+ 失败原因不再含糊

**1.2.0 的"一键更新"其实装不上** —— 实测 Windows 报 `0x80073D02`：
*「无法安装，因为需要关闭以下应用: MathLang.Editor」*。它**不允许边跑边装**。

### 这一版怎么改的

- **安装交给"外挂小助手"**：点【现在安装】→ 程序自己退出 → 由独立进程装包 → 装完自动打开新版。
  于是"应用被关掉"从异常变成**设计内的正常一步**，全程**不需要管理员、不弹 UAC**。
- **更新结果在下次启动时告诉你**：成功 → 「已更新到 1.2.1」＋更新说明；
  失败 → 「上次更新没成功」＋**具体原因**＋**安装包在哪个路径**（可复制、可手动装）。
- **下载有真进度**：独立的进度弹窗（进度条 + 已下/总量 + 百分比），可取消；
  下载完同一个窗口变成"准备安装"确认（明确告诉你窗口会关闭、约 10~20 秒后自动打开）。
- **失败原因具体化**：以前所有失败都压成一句"网络不可用"，现在区分
  「连接被拒绝（本机代理没在应答）」/「超时」/「证书校验失败」/「HTTP 4xx」/「下载不完整」，
  并且**自动重试一次**；超时 6 s → 10 s。
- **启动时顺手清**：更新成功后立刻删掉临时安装包；失败或"稍后再说"则留 3 天供重试，
  3 天后自动清掉。

### 安装

下 `mathlang-v1.2.1-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。
已经装过 `1.1.x` / `1.2.0` 的直接覆盖升级，数据与设置都保留。

绿色版：`mathlang-v1.2.1-win64-portable.zip`（解压即用；绿色版没有包身份，**不能**一键更新）。
