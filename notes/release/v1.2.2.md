## 1.2.2 · 验证版（内容与 1.2.1 完全相同）

**这一版只为验证"一键更新"链路，代码没有任何改动**（只抬了版本号）。

`1.2.1` 是第一个带"外挂小助手"的版本，但它自己没法验证"用一键更新把自己换掉" ——
那需要一个**更新的版本**存在。所以发这一个。

### 如果你在用 1.2.1

到 `设置 → 关于 → 更新 → 检查更新`，应当发现 1.2.2，然后：

```
【一键更新】→ 下载进度窗（进度条 + 已下/总量，可取消）
           → 同一个窗口变成「准备安装 1.2.2」
           → 【现在安装】→ 窗口关闭
           → 10~20 秒后自动打开新版
           → 弹「已更新到 1.2.2」→「关于」页 = 1.2.2
```

万一没自动打开：等 20 秒手动开一次，结果弹窗照样会出来
（成功 → 已更新；失败 → 具体原因 + **安装包路径**，可复制后手动装）。

### 安装（如果是从更旧的版本升级）

下 `mathlang-v1.2.2-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。
数据与设置都保留。绿色版：`mathlang-v1.2.2-win64-portable.zip`（绿色版不能一键更新）。
