## 1.2.3 · 设置不再"升级/重装就丢" + 一键更新真正能装

### 一、设置与草稿存到包外（**这条最重要**）

实测发现：打包版（MSIX）的 exe 在 `C:\Program Files\WindowsApps\...`（只读），
程序往它旁边写的时候，Windows 会**悄悄虚拟化**到
`%LOCALAPPDATA%\Packages\<包族名>\LocalCache\Roaming\…`。

结果就是：**关掉重开设置还在**（看起来正常），但那是**包内私有数据，卸载就整个删掉** ——
所以"卸载 → 装新版"之后，页位、字号、面板设置全没了（卸载时选"N 保留数据"也没用，
那只是脚本里的一句提示，没有任何机制在执行）。

现在：

- **打包版优先写 `%APPDATA%\mathlang\mathlang-session.json`** —— 用户的漫游目录，
  **卸载不动、升级继承**；
- **绿色版仍写 exe 同目录**（便携版就该跟着文件夹走，方便整个拷走）；
- **老用户第一次跑新版会自动迁移**：把包内那份旧文件搬出来，搬到新位置后删掉旧的；
- 设置页「暂存位置」显示**真实落点**；万一真的写不进去，那一行会**变红明说**
  （以前所有候选都失败时它是安静的）。

### 二、一键更新（外挂小助手）

上一版点【现在安装】后没反应 —— 根因是我启动小助手时传了字面量 `$pid`
（`-File` 的实参不做变量展开），参数绑定当场失败，脚本**一行都没跑**。
现在脚本不带任何参数，自己等 2.5 秒后安装、装完自动打开新版。

### 三、其余

- 下载/安装改成**界面内独立弹窗**（进度条 + 已下/总量 + 百分比，可取消）；
  下载完同一个窗口变成"准备安装"确认；
- 网络通道只报**能看见的**：hosts 把 GitHub 指向 127.0.0.1 ⇒
  「网络通道：本机加速工具」；否则 ⇒「正在尝试连接 GitHub」（不再写"或 VPN"这种猜的话）；
- 失败原因具体化（连接被拒 / 超时 / 证书 / HTTP 4xx / 下载不完整）＋自动重试一次；
- 更新结果在**下次启动**时告诉你：成功 →「已更新到 x.y.z」＋说明；
  失败 → 具体原因 ＋ **安装包在哪里**（可复制、可手动装）。

## 安装

下 `mathlang-v1.2.3-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`
（**直接覆盖升级，不要先卸载** —— 卸载会清掉包内数据；新版会把设置搬到包外，
从这版之后卸载/重装都不再丢设置）。

绿色版：`mathlang-v1.2.3-win64-portable.zip`（绿色版没有包身份，不能一键更新）。
