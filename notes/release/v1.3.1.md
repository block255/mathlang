## 1.3.1 · 导数撇与环境内子位点光标

1.3.0 发出去当天，你拿它写了一篇作业，报了两处。这版就是把那两处修掉 —— 没有新功能。

### 一、撇：`f` 现在能打两撇、三撇了

`f` 后面打一个撇（`f′`）再打一个撇，以前会红字 `[公式不完整]`。原因是第二个撇又挂了一个上标，
同一个基座上有了两个上标。现在第二个撇**并进已有的上标**里：

- `f` + 撇 + 撇 ⇒ `f′′`，再加 ⇒ `f′′′`；
- 撇后面挂了上标/下标再打撇也接得上（`f′′₊` 这种）；
- **面板按钮、快捷栏、键盘**三条入口行为一致；从正文里打 `f` 再连点面板撇也可以；
- 老稿子里"撇"是裸字符的（写作 `f'`）也接得上，不会报错；
- **光标始终停在撇的后面**（不会被带进上标，也不会跳到下标前面）。

### 二、矩阵 / 行列式 / 分段里的光标

在这些环境里给某个东西打**上标、下标、根号次数、对数的底**这类"更深一层"的位置时，
光标竖条以前是按**整格**的高度画的（看起来"对标左边那个字母，而不是指数"），
删掉指数之后还会往下出头一截。现在它会跟着**那一行**走；而"就在这一格里"的位置
仍然保持原来的画法（贴格子/行带）。

### 验证

- 全量自动化测试 **2149 条通过 / 0 失败**；
- 新守卫覆盖：连打 3 个撇（键盘 / 面板）、面板+键盘混用、正文起手、裸撇老稿、
  撇+下标后"整体后面"再打撇的落点；环境内子位点竖条与格级位点两条对照。

### 安装

下 `mathlang-v1.3.1-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。
已装 1.3.0 的可以在 `设置 → 关于 → 更新` 里点**一键更新**。
绿色版：`mathlang-v1.3.1-win64-portable.zip`（绿色版不能一键更新，但能下载更新包）。
