## 修复：部分机器安装失败（0x800B0109）

**现象**：在新机器上运行「双击我安装数语引擎.cmd」，即使在 UAC 里点了「是」，仍报

```
Add-AppxPackage : 部署失败，原因是 HRESULT: 0x80073CF0, 无法打开包。
错误 0x800B0109: 应用包或捆绑包中的签名的根证书必须是受信任的证书。
```

**原因**：安装脚本只把证书装进「**本机\TrustedPeople**」，而自签证书的**链根**要进「**Root**」；
而且那一步失败时脚本不检查退出码、照样继续装包。开发机上 `Root` 里早有一份（绿色版脚本装的），
所以一直没暴露这个问题。

**修法**（`scripts/pack_msix.ps1` 生成安装脚本的那段）：

1. 先**免管理员**装「当前用户 Root + TrustedPeople」——多数机器到这一步就够，**不弹 UAC**；
2. 仍失败才走 UAC 装「本机 Root + TrustedPeople」，然后重试一次；
3. 任一步失败都会**停住并说明原因**，不再静默继续（并提示可改用绿色版）。

## 安装

下 `mathlang-v1.1.1-win64-setup.zip`，解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。

装不上就换绿色版 `mathlang-v1.1.1-win64-portable.zip`：解压 → 双击 `启动数语引擎.cmd`（解压即用）。

> 程序本身没有改动（`1.1.1` 与 `1.1.0` 功能完全相同），只是安装脚本修好了。
