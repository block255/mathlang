## 1.3.0 · 编辑手感大幅优化

这一版没有新功能，全是**手感**：光标落在哪、空行是不是真的一行、删完之后光标停在哪、竖条画在哪。
二十来个"每天都会碰到、但每次都差一点"的地方，这一轮一次性对齐了。

### 一、落点：三条通道落到同一个地方

打字、符号面板、快捷栏、快捷键，现在插入前都过**同一条**"文末空行要补一个换行"的规则 ——
以前走面板/快捷键会差**一整行**。另外两处：

- **行内公式末尾按 Enter** 只往下走**一行**（以前一次跳两行）；
- **文首打字**不再凭空多出一个空行。

### 二、空行：有空格的行就是普通段落

在空行里打空格，空格**有宽度**、光标跟着往右走（以前这一行仍被当成"空行"，空格打不出来、光标直接消失）。

### 三、删除：光标留在**被删的那一行**

- 删掉一段内容、或删掉一个公式之后，光标停在**被删的那一行**（以前会跳到下一行，差将近一整行高）；
- 删末行（后面已经空着一行以上）也一样，不再往下跳；
- 删空一段时仍会顺手收掉它自己的那个换行 —— 视觉上就是**那一行整体消失**，一次退格、一步撤销。

### 四、光标竖条：行内放分式时回到主行

行内公式里放一个分式，光标竖条以前会按**分母**那一行画（低十几个像素），现在回到**主行带**。
这条是"多档字号"一起验的：14 / 16 / 18 / 20 / 24 px 下都不再漂。

### 五、表格与矩阵

- **参差行**（某一行比别的行少几格）点右侧空白，不再跳到整块的开头或末尾，而是落在该行最后一格的末尾；
- 列号、格子框、往格子里粘贴的落点在参差表上**对得上**（三张不等宽表逐格核过，零处不一致）；
- 光标不能停在 `\begin{…}` / `\end{…}` 这类看不见的记账文本里（八种环境形状都验过：矩阵、行列式、分段、对齐推导、嵌套）。

### 六、导入提示：只对真的"解释不了"的 `$$` 报警

导入时那句「第 N 行有行内 `$$`」现在按**围栏判据**报：

- 合法的**单行公式块**（`$$公式$$`）不再被误报 —— 以前每导入一份电子笔记就弹一串行号；
- 真正有问题的写法会被指出来，**并且指在开头那一行**（例如内容直接写在 `$$` 后面、闭合 `$$` 却挂在末行末尾 —— 这种写法会让整段 LaTeX 源码露出来）。

### 验证

- 全量自动化测试 **2125 条通过 / 0 失败**；
- 几何/光标类守卫在 **14 / 16 / 18 / 20 / 24 px 五档字号**下都跑；
- 导入提示的判据用**盘里 53 份真实 md**（约 411 处 `$$`）对过账。

### 安装

下 `mathlang-v1.3.0-win64-setup.zip` → 解压 → 双击 `数语引擎\双击我安装数语引擎.cmd`。
已装 1.2.10 的可以在 `设置 → 关于 → 更新` 里点**一键更新**。
绿色版：`mathlang-v1.3.0-win64-portable.zip`（绿色版不能一键更新，但能下载更新包）。
