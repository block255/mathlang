## 一、分类判据（三条，别再改）

1. ★ **kind 与分类解耦**：kind（template / symbol）**只决定插入行为**（模板要落"第一个空槽"），
   **不决定**归哪一类 —— 所以"求和 / 积分 / 矩阵 / 行列式"都是**模板**，却归在 符号 的子类里。
2. ★ **一级只有两个**：结构（**与主题无关的排版积木**）与 符号（各类数学记号，带子类）。
   （规格《S4》§B 原本还有"最近 / 收藏 / AI 常用"：**收藏 ≡ 快捷栏**、**最近已取消**、AI 常用待定。）
3. ★ **子类只有「符号」有**，正好 7 个：希腊 · 关系 · 运算 · 逻辑集合 · 箭头 · 特殊 · 线性代数。

**归属总量**（当前 JSON）：

- **符号/关系**：7 项
- **符号/箭头**：5 项
- **符号/逻辑集合**：18 项
- **符号/特殊**：11 项
- **符号/希腊**：17 项
- **符号/线性代数**：7 项
- **符号/运算**：16 项
- **结构**：12 项

## 二、alsoIn：少数项的**第二归属**（白名单）

**只批了 8 项**（用户 2026-10-17：可以一项多类，但别太多）：

| 项 | 主归属 | 第二归属 | 理由 |
|---|---|---|---|
| `bigcup` `bigcap` `biguplus` `bigsqcup`（多个集合的并/交） | 符号/逻辑集合 | 符号/运算 | 语义是集合运算，形态是 n 元算子（"像集合的求和"） |
| `bigvee` `bigwedge`（多"或"/多"且"） | 符号/逻辑集合 | 符号/运算 | 同上 |
| `therefore` `because`（所以/因为） | 符号/特殊 | 符号/逻辑集合 | 推理记号，两处都有人找 |

★ 除这 8 项，**一律单一归属**；找不到靠**跨分类搜索**兜底，不复制条目。

## 三、搜索关键词：三类来源 + 不撒滥

keywords **只影响搜索**（命中 + 排序），**永远不参与分类归属**。
★ "线性代数"**既是子类名、也是关键词** —— 不矛盾：子类这么叫；同时给行列式/矩阵等项挂上关键词，
搜索框打"线性代数"就直接出它们（与当前筛选无关）。

**① 学科/场景（最值钱）**

| 关键词 | 只挂在 |
|---|---|
| **线性代数** | `mat2` `det2` `det` `tr` `transpose` `otimes` `odot`（7 项，**不含"向量"**——它在结构里） |
| **微积分** | `int` `iint` `oint` `partial` `nabla` `lim` `infty` |
| **集合论** | `forall` `exists` `in` `notin` `subset` `subseteq` `cup` `cap` `emptyset` ＋ 6 个 n 元集合算子 |
| **数理逻辑** | `land` `lor` `neg` `Rightarrow` `Leftarrow` `iff` ＋ `bigvee` `bigwedge` ＋ `therefore` `because` |
| **几何** | `angle` `triangle` `perp` `parallel` `circ` |
| **组合** | `binom` `factorial` |

**② 口语/同义**：求和·累加·连加（`sum`）· 连乘·累乘·求积（`prod`）· 积分·定积分·不定积分（`int`）·
极限·趋近（`lim`）· 任意·全称·所有（`forall`）· 存在·至少一个（`exists`）· 属于·不属于（`in`/`notin`）·
子集·包含于 · 并集·交集·空集 · 不大于·至少（`le`）· 不小于·至少（`ge`）· **批量·多个集合·求并·求交**（6 个 n 元算子）·
偏导·偏微分·梯度·散度·旋度（`partial`/`nabla`）· 推出·蕴含·等价·充要（箭头）· 正负·加减·乘法·叉乘·除法（`pm`/`times`/`div`）

**③ LaTeX 反查**：命令名进 alias（`bigcup` `biguplus` `varnothing` …）。

**两条落地自检**（守卫里钉着）：
- 搜「线性代数」⇒ **只出那 7 项**；
- 搜「批量」⇒ **出 6 个 n 元集合算子**。

2. id 唯一、tex 非空。
3. kind 与分类解耦的**证据**：符号/运算 里有模板（`sum` `int`）、符号/逻辑集合 里有模板（`bigcup`）。
