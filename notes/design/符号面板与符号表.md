# 数语引擎 · 符号面板与符号表（v0.1，2026-10-13）

> **定位**：面板是**原则 2 的主路径** —— 用户不看编码，靠"点选/搜索"插符号与结构。
> **来源**：用户 2026-10-13 提出「面板要有搜索栏：输入『积分』能找到积分符号，输入『任意』能弹出 ∀」。
> 关联：插入语义与"一维缓冲区 + 提交规则"的接口见《技术选型与风险.md》4.0 / 5.1。

## 一、面板要解决的三件事

1. **找得到**：常用符号 ≤2 次点击可达；**搜中文名/口语别名**也要能出（用户脑子里是"任意"，不是 `\forall`）。
2. **插得对**：结构模板插入后，光标落在**第一个位点**，`Tab` 依次跳（位点定义见《技术选型与风险.md》5.1.1）。
3. **跟得上**：面板与光标**联动**——光标已在某槽内时，点选符号落在那个槽里。

## 二、符号表数据结构（草案）

```dart
class MathSymbol {
  final String id;             // 稳定标识，如 'int.definite'（快捷键绑定 / 最近使用都存它）
  final String latex;          // 纯符号写法，如 r'\int'
  final String? template;      // 带占位符的模板，如 r'\int_{□}^{□}'；null = 纯符号
  final int slots;             // 占位符个数（决定 Tab 跳位序）
  final String zh;             // 中文名，如 '定积分'
  final List<String> aliases;  // 别名/口语，如 ['积分','∫','int','jifen','微积分']
  final String category;       // 分类 id，如 'calculus'
  final String? panelLabel;    // 面板上显示的短标签（可缺省，用符号本身渲染）
  final List<String> keyHint;  // 默认快捷键（用户可在快捷键设置里改）
}
```

**规则**：`□` 表示占位符；**插入即把结构字符写进一维缓冲区**（`\int_{}^{}`），面板**不需要任何"结构魔法"**——它只是"插字符 + 移光标偏移"。这是 4.0 架构带来的最大简化。

## 三、搜索（用户 2026-10-13 要求）

| 输入 | 期望命中 | 靠什么字段 |
|---|---|---|
| `积分` / `定积分` | ∫ | `zh` / `aliases` |
| `任意` / `全称量词` / `∀` | ∀ | `zh` / `aliases` / `latex` |
| `jifen` / `ry` | ∫ / ∀ | **拼音首字母**（加分项，成本低、收益明显） |
| `\int` / `int` | ∫ | `latex`（也便于粘贴 LaTeX 后反查） |

**规则**
- 多字段 **OR** 匹配 + **子串**匹配（不只前缀：搜「积分」要能命中「定积分」「不定积分」）
- 排序：分类 → 最近使用 → 使用频次
- 搜索框内 **`Enter` = 插入第一个结果**；输入框为空时恢复"分类 + 最近使用"视图
- 搜不到时：给"相近符号"建议（沿用容错/问题清单那条思路：绝不静默空手而归）

## 四、面板布局

```
┌─ 符号面板 ─────────────┐
│ [搜索框]  ← Ctrl+/ 打开面板后可直接打字 │
├────────────────────────┤
│ 通用 | 希腊 | 运算 | 关系 | 集合 | 微积分 | 矩阵 | 多行 ...  ← Alt+1..9 直达
├────────────────────────┤
│ 符号网格（点选插入）        │
├────────────────────────┤
│ 最近使用                 │
└────────────────────────┘
```

- 分类页签用 `Alt+1..9` 直达（借 MathType Web 的 `Alt+数字` 约定）
- 移动端：面板收成底部抽屉（无物理键盘，全靠点选 + 搜索）

## 五、插入语义（与一维缓冲区 / 提交规则的接口）

1. **纯符号** → 往缓冲区插入 `latex`
2. **结构模板** → 插入 `template`（含花括号），**光标偏移落在第一个 `□`**
3. **连续插入**（插入积分后立刻插入根号）→ 落在**当前槽内**，不跳到文档末尾
4. 插入后**不进入任何"卡片"** —— 用户看到的只是渲染结果随之变化（4.0 原则）

### ★ 5.1 两类必须"自带槽"的模板（2026-10-15 补，用户提出）

**问题**（「数学与文字同权」的一个必然推论）：`\sum` / `\int` / `\log` / `\sin` 这类
**语法上需要内容跟在后面**的算子，如果靠"用户在公式**后面**接着打字"，必然出现两种结果：

```
$ \sum_{i=1}^{n} $ i      ← i 是正文（正体、无数学间距）✗ 用户多半不是这个意思
$ \sum_{i=1}^{n} i $      ← i 在数学里（斜体、数学间距）✓
```

**做法**：这类算子**由模板插入时自带槽**，内容天然落在**对象里面**：

| 类别 | 模板形态 | 说明 |
|---|---|---|
| 固定参数 | `\frac{□}{□}`、`\sqrt[□]{□}`、`\log_{□}□` | 参数槽就是内容的去处 |
| 带上下限 | `\sum_{□}^{□} □`、`\int_{□}^{□} □\,dx` | 上下限 + **被作用内容**各一个槽 |
| 多行环境 | `\begin{aligned} … \\ … \end{aligned}`、`\begin{cases} … \\ … \end{cases}` | 见 §5.2 |

⇒ **"内容跟在对象后面"这种需求被模板槽消灭** ⇒
「一个行内公式 = 一个**可见对象**」这条模型（《位点与结构导航》§4.0）**没有漏洞**，
"从公式外面退格 = 删整段"也不会误伤谁。

★ **不做魔法**：用户手打 `$` 或粘贴外部 LaTeX 造成"内容在对象外"（如 `$\sum_{i=1}^{n}$ i`）时，
**`i` 就是正文，我们不替他猜着搬进公式**（那与"渲染是源码的忠实投影"冲突）。
最多在提交点进「问题清单」提示（原则 5：**问题可见，不阻断**）。

### ★ 5.2 模板自带形态：多行 → 环境；环境内 `Enter` → 加一行

**引擎事实（2026-10-15 实测；权威记录见 `app/test/render/multiline_math_test.dart` 头部）**：

- **顶层 `\\` 非法** —— 公式会**当场炸**（行内、行间、末尾悬空都炸）
  ⇒ **不能**用「Enter 插 `\\`」做通用换行（方案已撤回）
- 但 `\begin{aligned}` / `\begin{cases}` **行内就能渲染**（实测 93.5 × 34.5 / 50.3 × 42.0）
  ⇒ ★★ **「多行」不强制「行间」** ⇒ 行内/行间**只由排版意图决定**（要不要独占一行居中），
  与内容长短、行数**无关** ⇒ **不做**"按长短自动升格 / 降格"（那会**静默重排**用户版面）

**由此定下模板的形态归属**：

| 模板 | 插入形态 | 理由 |
|---|---|---|
| `x^2`、`\frac`、`\sqrt`、单个符号 | **行内** `$…$` | 通常是句子里的一个成分 |
| `aligned`、`cases`、`matrix`、多行推导 | **行间** `$$…$$` | 通常是独立陈述；只有行间有居中与整行版式 |
| 用户明确要"公式独占一行居中" | **行间** | 这就是行间的定义 |

**环境内的 `Enter` = 加一行（插 `\\`）** —— 合法，因为它**在环境内部**。
⚠️ 这条依赖"光标在环境里"这个**结构判断**，归 **S4**；
本轮实现里 `insert_guard` 仍把块级换行推出数学段（安全底线），两者不冲突。

## 六、键盘路径（与《快捷键系统.md》保持一致）

| 键 | 作用 |

## 七、S4 验收标准

- [ ] 常用符号 ≤2 次点击可达；面板点选即插入
- [ ] 搜「任意」出 ∀、搜「积分」出 ∫、搜「jifen」出 ∫
- [ ] 模板插入后光标在第一个槽内，`Tab` 依次跳位
- [ ] 光标已在某槽内时，面板点选落在该槽（面板 ↔ 光标联动）
- [ ] 移动端（安卓）面板可点选可用，不依赖物理键盘
- [ ] ★ **需要内容的算子（`\sum`/`\int`/`\log`）插入后内容落在槽里** ——
      用户不需要去公式**后面**接着打字（否则内容会变成正文，见 §5.1）
- [ ] ★ 多行环境模板（`aligned`/`cases`）插成**行间**；**环境内 `Enter` = 加一行**
      （插 `\\`，只允许在环境内部 —— 顶层 `\\` 会让公式炸，见 §5.2）
- [ ] ★ **模板的形态不由内容长短决定**：不自动把行内升格、也不自动把行间降格（§5.2）
