# 数语引擎 · 快捷键系统（v0.2，2026-10-13 修订）

> **v0.2 修订要点**（相对 v0.1 草稿）
> 1. **数学类前缀 `Ctrl+Shift+*` → `Ctrl+Alt+*`**：v0.1 有 8 处撞上 **Chrome 独占键**（浏览器不允许页面拦截），详见第三节。
> 2. **上下标改用 `Ctrl+↑` / `Ctrl+↓`**（借 MathType Web 的真实约定，替换原自造的 `Ctrl+Shift+P/B`）。
> 3. **新增 `Alt+=` 插入行内公式**（Word / OneNote / PowerPoint 的全球通行键）。
> 4. **新增 `Alt+1..9` 切换符号面板分类页签**（借 MathType Web 的工具栏 `Alt+数字`）。
> 5. 每条绑定**标注来源**（见第五节）：哪些是市场通行惯例、哪些是我们自造的方言。
> 6. v0.1 的三项「待定」已定（见第六节）。

## 一、设计目标与范围

- 快捷键**只在有物理键盘的平台生效**（Web / 桌面；安卓接外接键盘可用）。**移动端一律用符号面板 + 手势**，不做软键位映射。
- 三组：**结构类**（块类型与导航）、**数学类**（插入模板）、**编辑类**（格式 / 撤销 / 跳位）。
- ★ **全部可在软件内自定义**并持久化，支持导入 / 导出 / 恢复默认。
  - 持久化载体：**Web 端 = localStorage（+ 导出 JSON 文件）**；**桌面 / 安卓 = 配置文件**（同一份 JSON 结构）。
  - 自定义界面本身属于「有物理键盘平台」的功能，放在设置页「快捷键」分区。
- 借鉴 Obsidian「LaTeX Suite」的**缩写展开**（输入触发式 snippet），**默认关闭**（避免与正常打字冲突）。
- 另有一条**有市场先例**的输入路径见第五节（MathType Autoformat：输入 `a/b` 直接变分式）——列为 S4 候选，默认关。

## 二、默认绑定（v0.2）

### 结构类

| 快捷键 | 作用 | 来源 |
|---|---|---|
| `Enter` | 新块（延续当前类型；空列表项回车退出列表） | 通用 |
| `Shift+Enter` | 块内换行 | 通用 |
| `Ctrl/Cmd+1/2/3` | 切为标题 1/2/3（再按一次回正文） | Typora 惯例 |
| `Ctrl/Cmd+Shift+7` | 有序列表 | **Google Docs** |
| `Ctrl/Cmd+Shift+8` | 无序列表 | **Google Docs** |
| `Ctrl/Cmd+Shift+9` | 引用块 | 自定（沿用 7/8/9 的邻居位） |
| `Ctrl/Cmd+Alt+C` | 代码块 | 自定（**避开 Chrome 的 `Ctrl+Shift+C` = 检查元素**） |
| `Ctrl/Cmd+Enter` | 插入分页符 | 自定 |
| `Tab` / `Shift+Tab` | 公式占位符间跳转（非公式态 = 列表缩进） | ⚠️ 待 S3 实测，见下注 |
| `↑ ↓ ← →` | 块间移动（公式卡片内 = 结构内导航） | 自定 |

> ⚠️ **Tab 的争议（重要，S3 前必须定）**：MathType Web 把 **`Tab` 留给界面控件导航**，公式内的结构移动用 **`↑↓←→`**；而 Word 公式内 `Tab` 是"跳下一个槽位"。两条路都有先例 → 我们**先按 `Tab` 跳槽位做**（模板插入后连按 Tab 最顺手），S3 期间与 `↑↓` 方案对比手感，再定稿。

### 数学类

| 快捷键 | 插入 | 渲染效果 | 来源 |
|---|---|---|---|
| `Alt+=` | 行内公式 `$□$` | 行内数学 | **Word / OneNote / PowerPoint**（全球通行） |
| `Ctrl/Cmd+Alt+E` | 行间公式 `$$□$$` | 独立居中 | 自定（E = display Equation） |
| `Ctrl/Cmd+Alt+F` | `\frac{□}{□}` | 上下结构分式（横线） | 自造方言（F = fraction） |
| `Ctrl/Cmd+Alt+R` | `\sqrt{□}` | 根号 | 自造方言（R = root） |
| `Ctrl/Cmd+↑` / `Ctrl/Cmd+↓` | `^{□}` / `_{□}` | 上标 / 下标 | **MathType Web** |
| `Ctrl/Cmd+Alt+I` | `\int_{□}^{□}` | 积分 | 自造方言（I = integral） |
| `Ctrl/Cmd+Alt+S` | `\sum_{□}^{□}` | 求和 | 自造方言（S = sum） |
| `Ctrl/Cmd+Alt+L` | `\lim_{□ \to □}` | 极限 | 自造方言（L = limit） |
| `Ctrl/Cmd+Alt+A` | `aligned` 模板（3 行、等号对齐） | 多行推导 | 自造方言（A = Align） |
| `Ctrl/Cmd+Alt+T` | `cases` 模板 | 分段函数 | 自造方言 |
| `Ctrl/Cmd+Alt+X` | `pmatrix` 2×2 模板 | 矩阵 | 自造方言（X = matriX） |
| `Ctrl/Cmd+Alt+B` | `\binom{□}{□}` | 组合数 | 自造方言（B = binomial） |

> **诚实说明**：仅有 `Alt+=` 与 `Ctrl+↑/↓` 两条在市场上真有对应；**`Ctrl+Alt+字母` 这一整套是我们自造的方言**（MathType Web 不提供字母模板键，它靠工具栏 `Alt+数字` + 点击）。自造的好处是不受旧习惯绑架、助记清晰；代价是学习成本由我们自己承担 → 这也是"软件内可改"必须做实的理由。
> 单符号（希腊字母等）走面板更快，不占快捷键。

### 光标在**数学结构内**时（★ 2026-10-13 修订：已无「公式卡片」）

> 架构改为**文字流内数学**（《技术选型与风险.md》4.0）后，**没有卡片、没有进出模式边界** —— 光标只是在同一个一维缓冲区里走进了某个**位点**。下表按键语义不变，"焦点上下文"由**当前位点**决定。

| 键 | 作用 | 来源 |
|---|---|---|
| `Tab` / `Shift+Tab` | 位点序下一个 / 上一个（争议见上注） | 见上注 |
| `↑` / `↓` | 在**竖直排布**的位点间移动（分子 ↔ 分母、矩阵行间） | **MathType Web** |
| `←` / `→` | 字符级 / 同层位点间移动（即跨边界结构导航） | 通用 |
| `Backspace` | **结构感知删除**（先删内容、空了再删结构，不留半个坏公式） | **MathType Web**（smart deleting） |
| `Esc` | 关闭符号面板 / 取消选区（**不再有"退出卡片"**） | 修订 |

| 快捷键 | 作用 | 来源 |

## 三、冲突与平台差异

### 3.1 浏览器独占键（**页面无法拦截**，只能避开）

v0.1 的 `Ctrl+Shift+*` 方案有 8 处落在这类键上，已全部改掉：

| 被占用的组合 | 浏览器的含义 |
|---|---|
| `Ctrl+Shift+R` | 强制刷新 |
| `Ctrl+Shift+I` | 开发者工具 |
| `Ctrl+Shift+C` | 检查元素（开 DevTools） |
| `Ctrl+Shift+B` | 显示/隐藏书签栏 |
| `Ctrl+Shift+M` | 切换用户 |
| `Ctrl+Shift+A` | 搜索标签页 |
| `Ctrl+Shift+T` | 重开已关闭的标签页 |
| `Ctrl+Shift+D` | 为所有标签页加书签 |
| `Ctrl+Shift+N` / `Ctrl+Shift+W` | 无痕窗口 / 关闭窗口 |
| `Ctrl+W` / `Ctrl+N` | 关闭/新建标签页 |

### 3.2 需要**实测能否拦截**的键（S1 加一条便宜验证）

| 组合 | 期望 | 若拦不住怎么办 |
|---|---|---|
| `Ctrl+S` | 拦下 → 我们保存文档 | 退让为 `Ctrl+Alt+S` |
| `Ctrl+P` | 拦下（若将来做打印/导出） | 不做快捷键 |
| `Tab` | 拦下 → 槽位跳转 | 改用 `↑↓` 做槽位导航（MathType 路线） |

### 3.3 其它

- **Windows 系统级**：避免 `Ctrl+Alt+方向键`（部分 Intel 显卡驱动用它旋转屏幕）；`Ctrl+Alt+Del` 不可用。本方案已避开（上下标用 `Ctrl+↑↓`，不带 Alt）。
- **AltGr 键盘布局**：`Ctrl+Alt+字母` 等价于 AltGr+字母 → 少数欧洲布局下会与输入字符冲突。**冲突检测里明确提示**，用户可自行改键。
- **自定义时做冲突检测**：保存前检查是否与已有绑定、浏览器独占键、系统保留键冲突，冲突则提示并拒绝。
- **显示适配**：macOS 显示 `Cmd`，其它显示 `Ctrl`；帮助页按平台显示。

## 四、持久化（JSON 草案）

```json
{
  "version": 1,
  "bindings": {
    "insert.frac":    ["Ctrl+Alt+F"],
    "insert.sqrt":    ["Ctrl+Alt+R"],
    "insert.sup":     ["Ctrl+ArrowUp"],
    "block.heading1": ["Ctrl+1"]
  },
  "snippets": {
    "enabled": false,
    "map": { "mk": "\\begin{pmatrix} □ & □ \\\\ □ & □ \\end{pmatrix}" }
  }
}
```

- 键位按**动作 id** 映射（不存界面文案，便于以后改文案 / 做多语言）
- 恢复默认 = 清空该文件；设置页提供导入 / 导出两个按钮
- Web 端落 **localStorage**，桌面 / 安卓落**配置文件**，**共用同一份结构**

## 五、来源与借鉴（v0.2 新增）

| 类别 | 内容 | 核实状态 |
|---|---|---|
| **有市场先例** | `Alt+=` 插入公式（Word 系）· `Ctrl+↑/↓` 上下标、`Esc` 退出、`↑↓` 槽位移动、`Alt+数字` 切面板页签（MathType Web）· `Ctrl+Shift+7/8/9` 列表（Google Docs）· `Ctrl+1/2/3` 标题（Typora）· `Ctrl+B/I/K/S/Z`（通用） | MathType Web 官方快捷键页**已逐字核对**；Google Docs 与 Word 两条为**依据通行认知、未逐字核实** |
| **自造方言** | `Ctrl+Alt+E/F/R/I/S/L/A/T/X/B` 这一整套模板插入键 · `Ctrl+Alt+C` 代码块 · `Ctrl+Alt+D` 源码视图 · `Ctrl+Enter` 分页符 · `Ctrl+/` 面板开关 | 无市场对应，本项目自行定义 |
| 参考链接 | MathType Web 快捷键：<https://wiris.helpjuice.com/en_US/interface-and-controls-mathtype-web/toolbar-and-keyboard-shortcuts> · Google Docs 快捷键：<https://support.google.com/docs/answer/179738> | |

**结论（设计取向）**：**能借就借，借不到才自造，并标明哪些是自造**——这样用户已有的肌肉记忆能直接迁移，自造部分也好向用户解释。因此后续若发现某条有更好的市场先例，**优先改成先例**而不是留着自造版。

**顺带发现（对原则 2 有利，列为 S4 候选）**：MathType 的 **Autoformat** 支持输入 `a/b` → 直接变分式、`a^b` / `a_b` → 上下标、`a>=b` → `≥`、输入 `(` 自动补 `()` 且光标居中，**在 Microsoft 365 与 Google Workspace 里默认开启**。这正好是"用户看不见编码也能写出公式"的另一条输入路径（打字即渲染，完全不含 LaTeX），与我们"符号面板 + 模板插入"是互补关系。**建议 S4 作为可关选项实现，默认关**（中文输入环境下 `a/b` 自动变形可能意外触发）。

| 原待定 | 决定 |
