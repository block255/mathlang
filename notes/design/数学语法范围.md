# 数语引擎 · 数学语法范围（草图 v0.1，2026-10-13）

> **依据**：渲染引擎 flutter_math_fork 的解析器**是 KaTeX 解析器的 Dart 移植**（官方 README 原话：与 KaTeX 相比"只有少数不支持的特性与解析差异"）。故本规格以 **KaTeX 方言**为基准。
> **重要**：本文件是**存储与解析层**的规格。界面上用户看不到这些命令（设计原则 2），符号面板负责把"点击"翻译成本文的写法。

## 一、定界符与职责划分

| 写法 | 归谁管 | 渲染效果 |
|---|---|---|
| `#` `##` `###`、`- `、`1. `、`> `、`---`、表格、`![]()` | **Markdown**（块类型） | 标题 / 列表 / 引用 / 分隔线 / 表格 / 图片 |
| `$x^2$` | **行内数学** | 随文字排版，与正文基线对齐 |
| `$$ ... $$` | **行间数学** | 独占一行、居中；内部可多行 |
| `\(...\)`、`\[...\]` | 兼容写法（可选支持） | 同上，便于粘贴外部 LaTeX |
| 代码块 / 行内代码里的 `$` | **不解析** | 原样显示（讲"美元"不会被当公式） |
| `\$` | 转义 | 真正的美元符号 |
| 数学区段内的 `_` `*` `\` | 归数学，**不做 md 解析** | 否则 `x_1`、`a*b` 会被 md 抢走 |

## 二、L1 基础数学（必须全支持）

| 类别 | 写法 | 示例 |
|---|---|---|
| 上下标 | `^`、`_`、`{}` | `x^2`、`a_{i,j}`、`x^{n+1}` |
| 分式 | `\frac{}{}`、`\dfrac`、`\tfrac` | **渲染为水平分数线 + 上下分子分母**（不是斜线） |
| 根式 | `\sqrt{}`、`\sqrt[n]{}` | `\sqrt[3]{x}` |
| 自适应括号 | `\left( \right)`、`\big \Big \bigg \Bigg` | 内容变高时括号自动撑大 |
| 希腊字母 | `\alpha … \omega`、`\Gamma … \Omega` | 24 个小写 + 常用大写 |
| 字母样式 | `\mathbb \mathcal \mathfrak \mathbf \mathrm \mathit \text` | `\mathbb{R}`、`\text{当 } x>0` |
| 运算符 | `+ - \times \div \cdot \pm \mp \ast \star \circ \bullet \oplus \otimes` | |
| 关系符 | `= \neq \approx \equiv \leq \geq \ll \gg \sim \simeq \propto \cong` | |
| 集合逻辑 | `\in \notin \subset \subseteq \cup \cap \setminus \emptyset \varnothing \forall \exists \neg \land \lor \implies \iff` | |
| 箭头 | `\to \rightarrow \leftarrow \leftrightarrow \Rightarrow \Leftarrow \Leftrightarrow \mapsto \uparrow \downarrow` | |
| 其它常用 | `\infty \partial \nabla \angle \perp \parallel \degree \prime \ldots \cdots \vdots \ddots` | |

## 三、L2 大型算符与函数（作业推导高频）

| 类别 | 写法 | 示例 |
|---|---|---|
| 大算符（带上限） | `\sum \prod \int \iint \iiint \oint \lim \max \min \sup \inf` | `\sum_{i=1}^{n} i`、`\lim_{x \to 0}` |
| 函数名（自动正体 + 正确间距） | `\sin \cos \tan \cot \sec \csc \arcsin \log \ln \lg \exp \det \gcd \deg` | |
| 重音与装饰 | `\vec \hat \bar \tilde \dot \ddot \overline \underline \overrightarrow \xrightarrow` | `\vec{v}`、`\overline{AB}` |
| 组合数 / 自定义函数名 | `\binom{n}{k}`、`\operatorname{rank}` | |

## 四、L3 多行环境与矩阵（"对齐"靠这层）

| 环境 | 用途 | 写法示例 |
|---|---|---|
| ★ `aligned` | **多行推导按 `&` 对齐、`\\` 换行** | `\begin{aligned} a &= b+c \\ &= d \end{aligned}` |
| `cases` | 分段函数 | `\begin{cases} x, & x>0 \\ -x, & x \leq 0 \end{cases}` |
| `matrix` 族 | 矩阵 / 行列式 | `pmatrix`（圆括号）、`bmatrix`（方括号）、`vmatrix`（行列式）、`matrix`（无括号） |
| `array` | 自定义列对齐 | `\begin{array}{lcr}` |
| `gathered` | 多行居中（不对齐） | |
| 间距 / 字号 | `\quad \qquad \, \: \; \!`、`\displaystyle \textstyle` | |

## 五、明确不支持（v1）

- **LaTeX 排版命令**：`\section`、`\begin{enumerate}`、`\tableofcontents`、`\footnote` → 结构交给块类型
- **公式编号与引用**：`\tag{}`、`\eqref{}`（v2 可考虑）
- **自定义宏**：`\newcommand`、`\def`、`\usepackage`
- **绘图 / 化学**：TikZ、`\ce{}`（mhchem）
- **断行控制宏**：渲染器不支持自动断行（见 `技术选型与风险.md` 风险 2）

## 六、容错行为（编辑器专属，必须有）

| 场景 | 期望行为 |
|---|---|
| 公式是半成品（`\frac{1}{` 未闭合） | **不崩**：该公式红底 + 简短原因，其它内容照常渲染（用渲染器的 `onErrorFallback`） |
| 命令拼错 / 不支持（`\alpa`） | 同上；汇总进「问题清单」面板，附"你是不是想写 `\alpha`"的建议 |
| 粘贴的 LaTeX 用了不支持的宏 | 同上；清单里给出位置与替代建议 |
| 中文直接写进数学（`x=中文`） | 渲染为字符或提示改用 `\text{中文}`（以 S1 实测为准） |
| 公式内多余空格 / 换行 | 忽略（数学模式空格本无意义），`\text{}` 内除外 |

★ **「问题清单」是本项目的关键体验**：把"静默渲染失败"变成可追溯、可一键复制的清单（沿用流水账「未识别通知」的成功做法）。

## 七、存储与互操作

- 一律存**标准 LaTeX 定界符**（`$...$` / `$$...$$`），不引入任何私有语法
- 因此：Typora / Obsidian / VS Code 都能直接打开；**AI 能直接读写并改写公式**
- 导出 md / txt 时公式写法**原样保留**，保证往返无损

## 八、给用户的「语法帮助」（内置页，未来做）
