# 数语引擎 · **剪贴板与跨语境粘贴**（讨论稿 v0.1，2026-10-23）

> 起因：用户 2026-10-23 公测反馈 —— 一个式子（如 `\frac{x^3}{\lvert\sin x\rvert^3}`）会被反复复制复用，
> 但它可能出现在**行内**、**行间块**、**极限后面**、**矩阵格 / 分子 / 根号里**……这些地方互相复制粘贴该怎么算？
>
> ★ 本文只定**语义**（复制出什么、粘进去变成什么），实现细节留到批 1 的改法里。
> 上游原则：《整体设计》§三-**平权** · 《编辑地基与手感》§7.1「**顶层无墙、内部有层**」「`$` 不是层级」。

---

## 一、一句话模型

> **复制 = 产出「自洽片段」；粘贴 = 把片段归一成目标语境。**

两个推论：

1. **定界符（`$` / `$$`）属于"语境"，不属于"内容"。**（§7.1：`$` 是**渲染提示**，不是语义墙）
   ⇒ 片段离开某个公式时**补**一对定界符（否则是半截源码）；片段进入另一个公式时**剥掉**定界符（否则成了嵌套 `$`）。
2. **片段没有"块地位"。** 从行间块里抠出来的一段，本质是"一个式子"，不是"一段排版" ⇒ 复制出去按**行内公式**算；
   只有**整块**（围栏完整）复制出来，才保持"块"。

---

## 二、复制：三条边界规则（顺序执行）

| 步 | 规则 | 为什么 |
|---|---|---|
| ① **段级配平** | 选区两端都在**同一个**数学段内部 ⇒ 包成 `$<片段>$`；只有一端在段内 ⇒ 把那一端**扩到段边界**（`$` 或围栏） | 半截源码没法用（A1 的根因） |
| ② **括号配平** | 片段里 `{}` 不平衡 ⇒ 向外扩到最近的平衡边界（仍在段内） | 拖选很容易切在 `\frac{` 中间 |
| ③ **控制词吸附** | 边界落在 `\frac` / `\text` 这类**控制词中间** ⇒ 扩到词首或词尾 | `\f` + `rac{…}` 两个都不能用 |

★ 三条都是**纯函数**（输入 `doc` + `(s,e)`，输出 `(s',e')`），可全域断言。

---

## 三、粘贴：按目标语境归一

**先定两件事**：目标语境（[`mathRegionAt`] 的唯一权威）＋ 载荷是不是**多行**（含 `\n`）。

```
若是多行载荷：
    目标在行间块内  ⇒ 整块内容替换（仍是一对围栏包着一个块）
    目标在行内公式内 ⇒ 提升成新行间块，插在该公式之后（块不嵌套、行内不许换行）
    目标在文字里    ⇒ 原样插入（既有行边界规则照旧）
否则（单行载荷）：
    目标在数学里（行内 / 块内 / 任何槽）
        · 载荷外层正好是一对 `$…$` / `$$…$$`（内部无别的 `$`）⇒ 剥掉外层，只插 tex
        · 载荷内部含 `$`（文字+公式混合）⇒ 推出到公式之后 ＋ 状态栏提示（不拆）
        · 其余（纯文字 / 纯 tex）⇒ **原样插入**（★ 与"打字"同口径）
    目标在文字里 ⇒ 原样插入
```

### ★ 决定 2 的依据（2026-10-23 实测）

用户提出「公式内本来就能输入文字」。探针实测（`Math.tex` 同一字体同一字号）：

```
raw  CJK 组：`x+中文+y`        w=138.06 h=20.0
text CJK 组：`x+\text{中文}+y` w=138.06 h=20.0   ← 逐像素同宽同高
```

⇒ 引擎**本来就把 CJK 当文本模式处理**，`\text{}` 与裸中文等价。
⇒ 粘贴若把中文"推出去"或偷偷包 `\text{}`，就与输入路径**成了两份判据**（违反 §六-2）。
⇒ **决定 2 = 丙（原样插入）**，与打字完全同口径。

| 目标语境 | 判据 | 载荷处理 |
|---|---|---|
| **文字里** | 不在任何数学段内 | **原样**插入（载荷自带 `$…$` ⇒ 行内公式；自带完整块 ⇒ 行间块） |
| **数学里** | 在 `$…$` 内（含**任何结构槽**：分子 / 根号内 / 上下标 / 矩阵格 / 极限后面） | 单行：剥外层定界符后插 tex；纯文字就照插（同打字） |
| **行间块里** | 在 `$$…$$` 内 | 单行同上；多行 / 整块 ⇒ **整块内容替换**（仍是一个块，见 F2） |

**两条兜底原则**（"混不进去"的情形，宁可说清楚也不硬塞）：

| 情形 | 处理 |
|---|---|
| **多行载荷 → 行内公式** | 行内不许换行 ⇒ **提升成新的行间块**插在公式之后（不劈开原公式） |
| **含 `$` 的混合载荷 → 数学里** | 拆不动 ⇒ **推出到公式之后** ＋ 状态栏说明 |

★ 兜底都必须**有状态栏说明**（原则 5「静默失败必须可见」）：不许"粘了但好像没反应"。

## 四、交叉表（★ 这张表是本稿要拍板的东西）

行 = 复制的是；列 = 粘到哪。

| 复制 \ 粘贴 | 文字里 | 行内公式里 / 结构槽里 | 行间块里 | 别的应用（记事本 / DeepSeek） |
|---|---|---|---|---|
| **R1 纯文字片段** | 文字 | **原样插入**（中文照插，与打字同口径） | 原样插入 | 文字 |
| **R2 行内公式里的片段**（如极限后面的分式） | 行内公式 | 剥 `$` ⇒ 插 tex | 剥 `$` ⇒ 插 tex | `$\frac{…}$` |
| **R3 整个行内公式**（`$…$`） | 行内公式（原样） | 剥 `$` ⇒ 插 tex | 剥 `$` ⇒ 插 tex | 源码 `$…$` |
| **R4 行间块里的一段** | 行内公式（**片段不是块**） | 剥 `$` ⇒ 插 tex | 剥 `$` ⇒ 插 tex | `$…$` |
| **R5 整个行间块**（多行，含围栏） | 行间块（原样） | **提升**成新块，插在公式之后 | **整块内容替换**（仍是一块） | 源码 `$$…$$` |
| **R6 文字 + 公式混合** | 原样 | 推出到公式之后 ＋ 提示（不拆） | 推出到块之后 ＋ 提示 | 源码 |

**用户举的那个例子**（极限后面的分式 `\frac{x^3}{\lvert\sin x\rvert^3}`）落在 **R2**：
复制 ⇒ 得到 `$\frac{x^3}{\lvert\sin x\rvert^3}$`（自洽、能单独渲染）；
粘到另一个 `\lim` 后面 / 矩阵格里 / 分子里 / 行间块里 ⇒ 剥掉 `$` 直接插 tex；
粘到正文里 ⇒ 就是一个行内公式。**一套规则覆盖所有"在什么结构里面"的情况。**

## 五、四点裁定（2026-10-23 用户拍板）

| # | 问题 | 裁定 |
|---|---|---|
| **1** | 从**行间块**里抠出来的片段，复制成 `$…$`（行内）还是 `$$…$$`（行间）？ | ✅ **`$…$`（甲）**：片段不是"一段排版"，它在哪个语境渲染由**粘贴目标**决定 |
| **2** | 纯文字粘进数学里 | ✅ **丙 原样插入**（用户指出"公式内本来就支持输入文字"；实测 `x+中文+y` 与 `x+\text{中文}+y` 逐像素同尺寸 ⇒ 与打字同口径，不偷偷包 `\text{}`、也不推出去） |
| **3** | 把**多行块**粘进行内公式里 | ✅ **甲 提升成新块插在公式之后**（块不嵌套、行内不许换行） |
| **4** | 复制**整块**时是否带 `$$` 围栏？ | ✅ **甲 带**：贴到别处还是块、贴到别的应用仍是完整源码 |

## 六、与"平权"的自检

| 过闸表问句 | 本稿的回答 |
|---|---|
| 有没有"进入 / 退出公式"的概念？ | 没有。粘贴只看**目标位置**是不是在数学里，这是位置事实，不是模式 |
| 光标在公式内 / 外行为不同？ | 只有"剥不剥定界符"这一处，且它是**纯语法事实**（§7.2 允许的两类之一） |
| 有没有把 `$` 当成一层？ | 相反：`$` 被当作**语境的属性**，复制/粘贴时由语境补或剥 |
| 有没有专用字号 / 底色 / 卡片？ | 无 |
