## 1. 不变量（任何布局都不许破坏）

1. ★★ **页宽 / 正文排版宽度不变**（`PageGeometry.contentWidth` = 174mm ≈ 657.6px）。
   ⇒ 面板、快捷栏、状态栏**一律不改正文宽度** ⇒ **分页一个像素都不变**。
   允许平移（改页面的 x 坐标），**禁止**改宽（挤压）。
2. ★ **新 UI 不进文档流**：面板 / 快捷栏 / 状态栏都不在 `DocView` 的排版树里。
3. ★ **一步可撤**：面板插入（符号 / 模板 / 自动建壳）都是**一次编辑**。
4. ★ **可疑要可见**：面板会自动包 `$…$`；包了几处走状态栏计数（已有 `EditViewStats.autoWrapped`，
   面板插入复用同一个字段，改名 `autoWrapped` → 语义扩成"编辑器替用户补的编码处数"）。

## 2. PC 骨架（桌面 / 平板横屏）

**宽屏（窗口宽 ≥ 1280）＝ 并排**：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：文档名（占位）            [符号] [导出] [设置]            │ 48px
├───────────────────────────────┬──────────────────────────────┤
│                               │ 快捷栏（8 格，S4-c）           │ 56px
│   A4 页面（794 × 1123）         ├──────────────────────────────┤
│   偏左：左外边距 24             │ 符号面板                      │ 420px
│   正文宽 657.6（不变）          │  搜索框 / 分类页签 / 网格      │
│   纵向滚动、页间留白 24         │  最近使用                     │
├───────────────────────────────┴──────────────────────────────┤
│ 状态栏：页 x/y · 字数 · 光标 · 编辑次数 · 自动包裹 N 处          │ 28px
└──────────────────────────────────────────────────────────────┘
```

- **页面偏左**（用户 2026-10-17 提）：页面左边缘 = 24px；右侧给面板/快捷栏留 420px。
  面板收起时页面**可以**回到居中（设置项，见 §6）。
- **窄屏（窗口宽 < 1280）＝ 覆盖**：页面居中；面板改成**覆盖式抽屉**（420px，从右滑出），
  不占位。★ 因为"改位置不改宽"，两种模式下**分页都不变**。

**数字（常量集中一处）**：

| 量 | 值 | 说明 |
|---|---|---|
| 页宽 / 页高 | 794 / 1123 px（= 210×297mm） | 已有 `PageGeometry` |
| 正文宽 | 657.6 px（174mm） | **不许变** |
| 页面左右外边距 | 24 px | 布局用，不进文档 |
| 页间留白 | 24 px | 已有 |
| 面板宽 | **420 px** = 8×44 + 7×6 + 2×12 | 由格数推算，**不写死** |

## 3. 手机骨架（窄屏、无物理键盘）

- **页面：整页等比缩放（fit-width）**，`scale = (屏宽 − 16) / 794`；**双指缩放**可再放大细看。
  ★ 缩放只改绘制，**不改排版** ⇒ 分页不变。
- **面板：右侧滑出，全宽覆盖**（宽度 = 屏宽，圆角抽屉 + 半透明遮罩）。
- 快捷栏（S4-c）：**底部**横条（手机更好按），桌面在面板上方。
- 顶栏收成一行图标；状态栏只在展开时显示页号/字数。

## 7. 插入语义（面板 → 缓冲区）

**先判光标位置，再决定插什么**（这是"数学与文本同权"的直接推论，用户 2026-10-17 确认方向）：

| 光标位置 | 动作 |
|---|---|
| **在数学段内**（含紧邻 ±1 格，例如刚停在 `$x$` 之后） | **并入那一段**：直接插 `tex`（`$x+1$`），**不**新建第二个 `$…$` |
| **在纯文字里** | **自动建壳**：插入 `$<tex>$`（模板则是 `$\frac{}{}$`），光标放进**第一个空槽** |
| **有选区** | 用 tex **替换选区**；若选区里已有数学段，就替换成 tex、不重复包 |

- 全部走 `insert_guard.planInsert`（**不绕过守门人**）+ `InsertPlan.padText`（行边界）；
- **一次编辑 = 一步撤销**；`EditViewStats.autoWrapped` 记"替用户补了几处编码"。

## 8. 验收与守卫（S4-b 的"改前必红"清单）

1. ★ **版面中性**：面板开 / 关、并排 / 覆盖 两种模式下，
   `PageGeometry.contentWidth` 与**分页结果**（每页单元 id 序列）**完全一致**。
2. ★ **插入语义**：文字里点「分式」⇒ 缓冲区是 `$\frac{}{}$` 且光标在分子槽；`edits == 1`；
   `$x$` 之后再点 `+` ⇒ 缓冲区是 `$x+$`（并入，不新建）。
3. **搜索**：`积分` / `jifen` / `int` 都能出 `\int`；前缀优先于包含。
4. **一格 = 一个对象**：点符号后正文里不许出现 `$`/`\frac` 之类源码（原则 1）。
