## 1. 不变量（任何布局都不许破坏）

1. ★★ **正文排版宽度不变**（`PageGeometry.contentWidth` = 174mm ≈ 657.6px）。
   ⇒ 面板 / 快捷栏 / 状态栏**一律不改正文宽度** ⇒ **分页一个像素都不变**。
   允许**平移**（改页面的 x 坐标），**禁止**改宽（挤压）。
2. ★ **新 UI 不进文档流**：面板 / 快捷栏 / 状态栏都不在 `DocView` 的排版树里。
3. ★ **一步可撤**：面板插入（符号 / 模板 / 自动建壳）都是**一次编辑**。
4. ★ **可疑要可见**：编辑器替用户补的编码（智能包裹、自动建壳）走状态栏计数
   （`EditViewStats.autoWrapped`）。

## 4. ★★★ 面板：**筛选器式**（2026-10-17 用户定稿，取代"子页 / 页签"）

> 用户原话大意：「不是给一个大面、放各种类把这个面占满，而是**这个面就当作选择的表格**；
> 上方**留出按钮来筛选显示**，初始为"全部"，可以更改 —— 选哪个类就只显示那个类的符号；
> 有二级子类的，选那个类时**再给一个二级子类的筛选按钮**，也是初始"全部"。」
> 另：「**收藏就是快捷栏**，它跟其他类不是并列的 —— 快捷栏放在**选择面板的上方独立显示**，
> 不管面板选哪个类，它都在上面。」

### 4.1 结构（三段，自上而下）

```
┌─ 编辑器右侧 ───────────────────────────────────────┐
│ 快捷栏（**独立组件**，8 格，常驻，不随筛选变化）        │ 56px
│  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│  │∫ ││√ ││Σ ││≤ ││π ││  ││  ││  │              │
│  └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │
├────────────────────────────────────────────────────┤
│ 🔍 [搜索：中文名 / 别名 / 拼音 / LaTeX …………]      │
│ [ 分类 ▾ 全部 ]  [ 子类 ▾ 全部 ]        ← 两个筛选按钮 │
├────────────────────────────────────────────────────┤
│ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│ │∫ ││∬ ││∮ ││Σ ││∏ ││√ ││□ ││… │              │  ← **面 = 表格**
│ └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │     (当前筛选的项)
│ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│ │  ││  ││  ││  ││  ││  ││  ││  │              │
│ └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │
└────────────────────────────────────────────────────┘
```

**三条规则**

1. **面板主体只有一个网格**（"面 = 表格"）—— 没有分类列表页、没有 tab 行、没有返回按钮。
2. **筛选＝两个按钮**（不是把分类铺满面板）：
   - `分类 ▾`：`全部`（默认）· `最近` · `结构` · `符号` · `线代` · `箭头` · `特殊` …；
   - `子类 ▾`：**只在所选分类有 `subgroup` 时才可用**（初始 `全部`）；
     例：分类选「符号」⇒ 子类候选 = 全部 / 希腊 / 关系 / 运算 / 逻辑集合 / 箭头 / 特殊。
   - 两个筛选**互相收窄**（分类 ∩ 子类）；`全部` = 不限制。
3. **搜索优先于筛选**：有查询时显示**跨分类**的搜索结果；清空查询 ⇒ 回到原来的筛选状态。

### 4.2 交互与状态

| 动作 | 行为 |
|---|---|
| 打开面板 | 恢复上次的「分类 / 子类」筛选（会话内记忆），初始都是"全部" |
| 点「分类 ▾」 | 弹出菜单选中一项 ⇒ 网格立刻只显示该类；若该类无子类 ⇒ 「子类」自动回"全部"并**置灰** |
| 点某个符号 | 按 §7 插入；**面板保持打开**、筛选不变（连续插入） |
| 点「快捷栏」的空格 | 进入**赋值模式**（该格高亮）⇒ 下一次点面板里的任意符号就赋给它；`Esc` 取消 |
| `Alt+1..8` | 直接插入快捷栏第 N 格（不管面板开没开）|
| 长按/悬停格子 | 显示该符号的**渲染预览**（大图 + 名称 + LaTeX） |

### 4.3 数据（`assets/symbols.json`）

- 一级 = `group`；二级 = `subgroup`（字段已有，**数据大多为空 ⇒ b2 要补**，至少把"符号/线代"补上）。
- 分类筛选里 **`最近`** 是**虚拟分类**（MRU，不进 JSON）；**收藏不在这里** —— 收藏 ≡ 快捷栏（§5）。
- 每个分类的显示顺序 = JSON 里第一次出现的顺序。

### 4.4 被否的三个方案（留档，别再捡回来）

| 方案 | 线框要点 | 为什么否 |
|---|---|---|
| **A 子页（钻取）** | 分类列表页 → 点进该分类页 + `← 返回` | 每次切分类要 **2 次点击** + 需要"返回"心智；分类少时多一层没意义 |
| **B 真页签**（旧稿原意） | 一行 tab 常驻、一次显示一页 | 分类一多就要**横向滚动**，退化成"一行 chip"（= b1 的问题） |
| **C 混合** | 一级 3 个 tab + 二级子页列表 | 二级还是"子页"（两次点击 + 返回） |

★ 四者**共用**：网格、搜索、插入语义、快捷栏；差别只在"导航壳"⇒ 定稿后改动很小。

## 5. ★★ 快捷栏（= 收藏；独立组件，在面板**上方**）

> 用户 2026-10-17：「**收藏也就是快捷栏**……它跟其他类并不是并列的，而是**放在选择面板的上方独立显示**；
> 不管选择面板选哪个类，这个快捷栏都在上面显示着。」

- **形态**：一格一行，**8 格**（= 面板一排的格数，同一常量 `kSymbolGridColumns`，设置可调）。
- **位置**：**面板上方**（桌面与手机同一种默认）；设置可切「底部横条」。
  ★ **面板收起时**：快捷栏可**独立常驻在页面底部**（原设计稿 C1「可独立常驻、可隐藏」）——**待确认**（§10-6）。
- **赋值**（用户给的方式，不变）：**先点某个栏位"选中"** ⇒ 再点面板里任意符号 ⇒ 放进该格（替换旧的）；
  空格点一下进入赋值模式、`Esc` 取消；长按格子可清空。
- **使用**：`Alt+1..8` 直接插入第 N 格；也可直接点格子插入。
- **与筛选无关**：快捷栏**不受**「分类/子类」筛选影响，永远显示这固定的 8 格。
- **数据**：`favorites: [id, null, id, …]`（长度 = 格数；`null` = 空格）——"空位"就是快捷栏的空格。

```
┌─ 快捷栏（8 格）─────────────────────────────────────┐
│ ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐  │
│ │ ∫  ││ √  ││ Σ  ││ ≤  ││ π  ││ ＋ ││    ││    │  │  ← 空格 = 可赋值位
│ └────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘  │
└────────────────────────────────────────────────────┘
   ↑ 与下面的"分类/子类筛选"完全独立：切筛选时它一动不动
```

## 6. ★★ 设置：**独立设置页**（2026-10-17 用户提出）

> 用户原话大意：「设置可以设置一个单独的**设置页面**，而不是这样一个按钮列表，这样不太好精细调整。」

形态：**独立页面**（路由 `/settings`）。PC：左侧分组导航 + 右侧内容；手机：列表 → 点进分组。

| 分组 | 条目 |
|---|---|
| **文档与排版** | 正文字号、行距、页边距、页眉文字、**行间公式字号** |
| **布局** | 页面位置（**偏左 / 居中**）、面板形态（**并排 / 覆盖 / 自动**）、并排阈值（高级）、面板宽、网格列数 |
| **面板** | 默认打开、显示"最近"、显示"收藏"、长按预览开关、分类列表里显示条数 |
| **快捷栏** | 位置（**面板上方 / 底部**）、格数、每格内容（点进去改）、恢复默认 |
| **状态栏** | 显示 / 隐藏、显示哪些项（页号 · 字数 · 光标 · 编辑次数 · 自动包裹） |
| **快捷键** | 默认表 + 每条 **启用/禁用 + 自定义组合键 + 恢复默认**（含 `sqrt/sum` 这类**词触发**的词表与终止符） |
| **智能输入** | 自动补命令分隔符、`/`→分式、快捷输入表；**智能包裹只读说明**（无开关，见《S4》§A2） |
| **高级** | 源码视图开关、诊断清单、清空本地缓存 |
| **关于** | 版本、构建、许可 |

- **单一来源**：`AppSettings`（布局/界面）＋ `ShortcutSettings`（快捷键/词触发）。
  **持久化随 S4-e「本地暂存」一起做**（现在内存态）。
- 设置页**不进文档流**；打开/关闭不影响文档与分页。

## 7. 插入语义（面板 → 缓冲区）

| 光标位置 | 动作 |
|---|---|
| **在数学段里**（含紧邻 ±1 格，如刚停在 `$x$` 之后） | **并入那一段**：插 `tex`（`$x+$`），**不**新建第二个 `$…$` |
| **在纯文字里** | **自动建壳**：插 `$<tex>$`（模板 `$\frac{}{}$`），光标进**第一个空槽** |
| **有选区** | 用 tex **替换选区**；选区内已有数学段 ⇒ 替换成 tex、不重复包 |

- 全部走 `insert_guard.planInsert`（行边界 ③④⑤ 照旧）⇒ **一次编辑 = 一步撤销**；
  `EditViewStats.autoWrapped` 记"替用户补了几处编码"。

## 9. 决策记录（2026-10-17，**别再重开**）

1. **面板宽**：先取 `n×44+(n−1)×6+24`（8 列 ⇒ 418）；**等看到实际界面再调**（用户："暂时不好感觉"）。
   ★ 子页落地后可能**不再需要 8 列**（页签才需要"一屏看全部分类"）⇒ 届时建议 5–6 列、面板 320–360。
2. **并排阈值 1280**：≥1280 并排（页面偏左），<1280 覆盖。
3. **PC 页面偏左**（右侧给面板 + 快捷栏）；★ **只挪位置、不改正文宽**。
4. **手机**：整页 fit-width ＋ **右侧全宽滑出**抽屉；状态栏**默认隐藏**。
5. **快捷栏默认在面板上方**（桌面与手机一致），设置可切底部。
6. **设置 = 独立设置页**（分组见 §6），含**快捷键自定义**（启用/禁用 + 改键 + 恢复默认）。
7. ★ **面板分类 = 子页导航**（不是一行页签），支持**二级子类**。
8. **插入语义**：并入 / 建壳 / 替换（§7）——"用户不写编码"与"数学与文本同权"的直接推论。
9. ★★ **面板 = 筛选器式**：**面 = 表格**（只有一个网格），分类/子类各一个**筛选按钮**，初始都"全部"；
   **不做**分类列表页、**不做** tab 行、**不做**返回。子类筛选只在所选分类有 `subgroup` 时可用。
10. ★★ **收藏 ≡ 快捷栏**：8 格、**独立组件、在面板上方**、不随筛选变化；先点栏位再点符号赋值、`Alt+1..8` 插入。
