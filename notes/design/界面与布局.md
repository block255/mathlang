## 1. 不变量（任何布局都不许破坏）

1. ★★ **正文排版宽度不变**（`PageGeometry.contentWidth` = 174mm ≈ 657.6px）。
   ⇒ 面板 / 快捷栏 / 状态栏**一律不改正文宽度** ⇒ **分页一个像素都不变**。
   允许**平移**（改页面的 x 坐标），**禁止**改宽（挤压）。
2. ★ **新 UI 不进文档流**：面板 / 快捷栏 / 状态栏都不在 `DocView` 的排版树里。
3. ★ **一步可撤**：面板插入（符号 / 模板 / 自动建壳）都是**一次编辑**。
4. ★ **可疑要可见**：编辑器替用户补的编码（智能包裹、自动建壳）走状态栏计数
   （`EditViewStats.autoWrapped`）。

## 2. PC 骨架

**宽屏（窗口 ≥ 1280）＝ 并排**：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：文档名            [符号] [设置]                          │ 48px
├───────────────────────────────┬──────────────────────────────┤
│                               │ 快捷栏（8 格，S4-c）           │ 56px
│   A4 页面 794×1123，**偏左**    ├──────────────────────────────┤
│   正文宽 657.6（恒定）          │ 符号面板（宽 = 格数推算）      │
│   纵向滚动、页间留白 24         │  搜索 / 分类子页 / 网格        │
├───────────────────────────────┴──────────────────────────────┤
│ 状态栏：字数 · 光标 · 编辑次数 · 自动包裹 N 处                  │ 28px
└──────────────────────────────────────────────────────────────┘
```

**窄屏（< 1280）＝ 覆盖**：页面居中；面板改为覆盖式抽屉（从右滑出），不占位。

| 量 | 值 | 说明 |
|---|---|---|
| 页宽 / 页高 | 794 / 1123 px（210×297mm） | `PageGeometry` |
| 正文宽 | **657.6 px** | 不许变 |
| 页面外边距 / 页间留白 / 列间距 | 24 / 24 / 24 px | `LayoutMetrics` |
| 面板宽 | **由格数推算**：`n×44 + (n−1)×6 + 24` | 8 列 ⇒ 418；子页之后可能收窄（见 §9-1） |
| 快捷栏高 | 56 px | 面板**上方**，设置可切底部 |
| 顶栏 / 状态栏 | 48 / 28 px | |
| 并排阈值 | 1280 px | 低于它转覆盖 |

## 3. 手机骨架

- **页面**：整页等比缩放（fit-width，`scale = (屏宽 − 16) / 794`）＋ 双指缩放。
  ★ 缩放只改绘制、**不改排版** ⇒ 分页不变。
- **面板**：**右侧全宽滑出**（宽度 = 屏宽）+ 半透明遮罩，点遮罩关闭。
- **快捷栏**：默认也在**面板上方**（设置可切底部横条）。
- **状态栏**：**默认隐藏**（设置里可开）。
- 顶栏收成一行图标（文档名可省）。

## 4. ★★ 面板：**子页导航**（2026-10-17 用户提出，取代"分类页签"）

> 用户原话大意：「分类是做成**子页型**吧，不过现在这里是子列（一行页签）。用**子页**的话空间会宽松很多，
> 可以选分类来显示。而且有的子类还可以选**二级子类**。」

### 4.1 三层结构

```
【面板内是一个"小应用"，有自己的导航】

┌ 搜索框（常驻顶部：中文名 / 别名 / 拼音 / LaTeX）─────────────┐
│  有查询 ⇒ 显示**搜索结果页**（跨分类），清空查询 ⇒ 回到原来的页  │
├──────────────────────────────────────────────────────────┤
│ 一级页：**分类列表**                                          │
│   最近 · 收藏 · 结构 · 符号 · 线代 · 箭头 · 特殊 …            │
│   每格 = 图标 / 代表符号 + 分类名 + 条数；点一格 ⇒ 进二级页      │
├──────────────────────────────────────────────────────────┤
│ 二级页：**该分类的内容（网格）**                                │
│   顶部：[← 返回] 分类名          右侧：子类筛选（若该分类有子类） │
│   网格：结构模板优先，其余按库内顺序；点选 ⇒ 插入                 │
├──────────────────────────────────────────────────────────┤
│ 三级（**只对有子类的分类**）：子类筛选条                        │
│   例：符号 → 希腊 / 关系 / 运算 / 逻辑集合 / 箭头 / 特殊          │
│       线代 → 矩阵 / 行列式 / 向量                              │
│   ★ 子类**不另写表**：由 JSON 的 `subgroup` 字段自动推出（去重保序）│
└──────────────────────────────────────────────────────────┘
```

- **为什么子页更好**（用户给的理由，记下来免得以后又改回页签）：
  ① 一行页签装不下 8 个以上的分类（现在的实现已经要横向滚动）；
  ② 子页里**只显示一个分类**，格子可以更大、标签可以两行，不用挤；
  ③ 分类可以有**二级子类**，页签形态没地方放第三层。
- **键盘**：`Alt+1..N` = 直达一级列表里的第 N 个分类（进二级页）；`Esc` = 返回一级；
  搜索框有焦点时 `↑↓` 选结果、`Enter` 插入第一个。
- **状态**（记忆）：进入过哪个分类、上次停留在哪一页（会话内保存）。
- **插入后面板保持打开**（连续插入）；`Esc` / 点正文关闭面板。

### 4.2 数据（`assets/symbols.json`）

- 一级分类 = `group`；二级子类 = `subgroup`（**字段已有，当前数据大多为空 ⇒ 见 §8**）。
- 每个分类的**显示顺序** = JSON 里第一次出现的顺序；`最近` / `收藏` 是**虚拟分类**（不进 JSON）。

## 5. 快捷栏（S4-c）

- 位置：**默认面板上方**（桌面与手机同一种默认），设置可切**底部横条**。
- **格数 = 面板一排的格数**（同一常量 `kSymbolGridColumns`，默认 8，设置可调）。
- 赋值：先点栏位"选中" ⇒ 再点面板里的符号 ⇒ 放进该栏位；`Alt+1..8` 插入对应栏位。

## 6. ★★ 设置：**独立设置页**（2026-10-17 用户提出）

> 用户原话大意：「设置可以设置一个单独的**设置页面**，而不是这样一个按钮列表，这样不太好精细调整。」

形态：**独立页面**（路由 `/settings`）。PC：左侧分组导航 + 右侧内容；手机：列表 → 点进分组。

| 分组 | 条目 |
|---|---|
| **文档与排版** | 正文字号、行距、页边距、页眉文字、**行间公式字号** |
| **布局** | 页面位置（**偏左 / 居中**）、面板形态（**并排 / 覆盖 / 自动**）、并排阈值（高级）、面板宽、网格列数 |
| **面板** | 默认打开、显示"最近"、显示"收藏"、长按预览开关、分类列表里显示条数 |
| **快捷栏** | 位置（**面板上方 / 底部**）、格数、每格内容（点进去改）、恢复默认 |
| **状态栏** | 显示 / 隐藏、显示哪些项（页号 · 字数 · 光标 · 编辑次数 · 自动包裹） |
| **快捷键** | 默认表 + 每条 **启用/禁用 + 自定义组合键 + 恢复默认**（含 `sqrt/sum` 这类**词触发**的词表与终止符） |
| **智能输入** | 自动补命令分隔符、`/`→分式、快捷输入表；**智能包裹只读说明**（无开关，见《S4》§A2） |
| **高级** | 源码视图开关、诊断清单、清空本地缓存 |
| **关于** | 版本、构建、许可 |

- **单一来源**：`AppSettings`（布局/界面）＋ `ShortcutSettings`（快捷键/词触发）。
  **持久化随 S4-e「本地暂存」一起做**（现在内存态）。
- 设置页**不进文档流**；打开/关闭不影响文档与分页。

## 7. 插入语义（面板 → 缓冲区）

| 光标位置 | 动作 |
|---|---|
| **在数学段里**（含紧邻 ±1 格，如刚停在 `$x$` 之后） | **并入那一段**：插 `tex`（`$x+$`），**不**新建第二个 `$…$` |
| **在纯文字里** | **自动建壳**：插 `$<tex>$`（模板 `$\frac{}{}$`），光标进**第一个空槽** |
| **有选区** | 用 tex **替换选区**；选区内已有数学段 ⇒ 替换成 tex、不重复包 |

- 全部走 `insert_guard.planInsert`（行边界 ③④⑤ 照旧）⇒ **一次编辑 = 一步撤销**；
  `EditViewStats.autoWrapped` 记"替用户补了几处编码"。

## 9. 决策记录（2026-10-17，**别再重开**）

1. **面板宽**：先取 `n×44+(n−1)×6+24`（8 列 ⇒ 418）；**等看到实际界面再调**（用户："暂时不好感觉"）。
   ★ 子页落地后可能**不再需要 8 列**（页签才需要"一屏看全部分类"）⇒ 届时建议 5–6 列、面板 320–360。
2. **并排阈值 1280**：≥1280 并排（页面偏左），<1280 覆盖。
3. **PC 页面偏左**（右侧给面板 + 快捷栏）；★ **只挪位置、不改正文宽**。
4. **手机**：整页 fit-width ＋ **右侧全宽滑出**抽屉；状态栏**默认隐藏**。
5. **快捷栏默认在面板上方**（桌面与手机一致），设置可切底部。
6. **设置 = 独立设置页**（分组见 §6），含**快捷键自定义**（启用/禁用 + 改键 + 恢复默认）。
7. ★ **面板分类 = 子页导航**（不是一行页签），支持**二级子类**。
8. **插入语义**：并入 / 建壳 / 替换（§7）——"用户不写编码"与"数学与文本同权"的直接推论。
