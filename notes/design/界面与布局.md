## 1. 不变量（任何布局都不许破坏）

1. ★★ **正文排版宽度不变**（`PageGeometry.contentWidth` = 174mm ≈ 657.6px）。
   ⇒ 面板 / 快捷栏 / 状态栏**一律不改正文宽度** ⇒ **分页一个像素都不变**。
   允许**平移**（改页面的 x 坐标），**禁止**改宽（挤压）。
2. ★ **新 UI 不进文档流**：面板 / 快捷栏 / 状态栏都不在 `DocView` 的排版树里。
3. ★ **一步可撤**：面板插入（符号 / 模板 / 自动建壳）都是**一次编辑**。
4. ★ **可疑要可见**：编辑器替用户补的编码（智能包裹、自动建壳）走状态栏计数
   （`EditViewStats.autoWrapped`）。

## 4. ★★★ 面板：**筛选器式**（2026-10-17 用户定稿，取代"子页 / 页签"）

> 用户原话大意：「不是给一个大面、放各种类把这个面占满，而是**这个面就当作选择的表格**；
> 上方**留出按钮来筛选显示**，初始为"全部"，可以更改 —— 选哪个类就只显示那个类的符号；
> 有二级子类的，选那个类时**再给一个二级子类的筛选按钮**，也是初始"全部"。」
> 另：「**收藏就是快捷栏**，它跟其他类不是并列的 —— 快捷栏放在**选择面板的上方独立显示**，
> 不管面板选哪个类，它都在上面。」

### 4.1 结构（三段，自上而下）

```
┌─ 编辑器右侧 ───────────────────────────────────────┐
│ 快捷栏（独立组件 · 自己的收起按钮 · 不随筛选变化）      │ 56px
│  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│  │∫ ││√ ││Σ ││≤ ││π ││＋ ││  ││  │              │
│  └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │
├────────────────────────────────────────────────────┤
│ 🔍 [搜索：中文名 / 别名 / 拼音 / LaTeX …………]      │
│ [ 分类 ▾ 全部 ]  [ 子类 ▾ 全部 ]        ← 两个筛选按钮 │
├────────────────────────────────────────────────────┤
│ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│ │∫ ││∬ ││∮ ││Σ ││∏ ││√ ││∫ ││… │              │ ← **面 = 表格**
│ └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │   （当前筛选的项）
│ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐              │
│ │  ││  ││  ││  ││  ││  ││  ││  │              │
│ └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘              │
└────────────────────────────────────────────────────┘
```

**三条规则**

1. **面板主体只有一个网格**（"面 = 表格"）—— 没有分类列表页、没有 tab 行、没有返回按钮。
2. **筛选＝两个下拉按钮**（不是把分类铺满面板）：
   - `分类 ▾`：候选 = **`全部`（默认）· `结构` · `符号`**（+ 将来"AI 常用"）。
     ★ 这就是规格里的**全部一级分类**（《S4》§B：最近 · 收藏 · 结构 · 符号 · AI 常用；
     其中**收藏 ≡ 快捷栏**、**最近已取消**，所以只剩结构/符号）。
   - `子类 ▾`：**只有「符号」有子类**（`全部` + 该分类的 `subgroup` 去重保序）：
     `希腊` · `关系` · `运算` · `逻辑集合` · `箭头` · `特殊` · `线性代数`。
     其它分类（结构）⇒ 该按钮**置灰**。
   - 两个筛选**互相收窄**（分类 ∩ 子类）；`全部` = 不限制。
3. **搜索优先于筛选**：有查询时显示**跨分类**的搜索结果；清空查询 ⇒ 回到原来的筛选状态。

★ **`keywords` 只用于搜索，不参与分类**（见 §4.3(4)）。
   ★ **"线性代数"既是子类名、也可以当关键词** —— 两者不冲突：子类名叫它；同时给 `行列式/矩阵`
   挂上关键词，让搜索框打"线性代数"就直接出它们（与当前筛选无关）。

### 4.2 交互与状态

| 动作 | 行为 |
|---|---|
| 打开面板 | 恢复上次的「分类 / 子类」筛选（会话内记忆），初始都是"全部" |
| 点「分类 ▾」 | 弹出菜单选中一项 ⇒ 网格立刻只显示该类；若该类无子类 ⇒ 「子类」自动回"全部"并**置灰** |
| 点某个符号 | 按 §7 插入；**面板保持打开**、筛选不变（连续插入） |
| 点「快捷栏」的空格 | 进入**赋值模式**（该格高亮）⇒ 下一次点面板里的任意符号就赋给它；`Esc` 取消 |
| `Alt+1..8` | 直接插入快捷栏第 N 格（不管面板开没开）|
| 长按/悬停格子 | 显示该符号的**渲染预览**（大图 + 名称 + LaTeX） |

### 4.3 ★★ 分类口径（判据 + 逐项归属，2026-10-17 讨论中）

#### (1) 先说清一个**冲突**（必须二选一）

规格里同时有两句话：
- 《S4》§B：「分类 = 最近 · 收藏 · **结构** · **符号**（带子类） · AI 常用」——一级按**形态**分
  （结构 = 带空槽的模板；符号 = 插进去就完事的单个记号）；
- 同一行又写：「符号子类：… · **线性代数（行列式/矩阵）**」——把**矩阵/行列式（模板）**放进了**符号**的
  子类里，与"按形态分"矛盾。

**处置（建议，待用户确认）**：**`kind`（模板 / 符号）与 `group`（分类）解耦** ——
"是不是模板"只决定**插入行为**（要不要落第一槽），**不决定**它属于哪个分类。
⇒ 分类按**主题**分；`结构` 这一级专门留给"**与主题无关的排版积木**"。

#### (2) 推荐口径（C）

| 一级 | 内容 |
|---|---|
| **`结构`** | **与主题无关的排版积木**：分式、根号、n 次根、上标、下标、绝对值、括号、上划线、帽子、向量、分段、对齐推导 |
| **`符号`**（带子类） | 各类**数学记号**（含带槽的算子模板） |

`符号` 的 7 个子类：

| 子类 | 放什么 |
|---|---|
| **希腊** | `α β γ δ Δ ε θ λ μ π ρ σ Σ τ φ ω Ω` |
| **关系** | `≤ ≥ ≠ ≈ ≡ ∼ ∝` |
| **运算** | `± ∓ × ÷ ·` ＋ **`∑`（求和）`∏`（连乘）`∫ ∬ ∮`（积分）`lim`（极限）`log`（对数）** ＋ `!` ＋ **批量的 ∪/∩/∨/∧（`\bigcup \bigcap \biguplus \bigsqcup \bigvee \bigwedge`，与「逻辑集合」双归属）** |
| **逻辑集合** | `∀`（任意）`∃`（存在）`∈ ∉ ⊂ ⊆ ∪ ∩ ∅` `∧ ∨ ¬` ＋ **批量的交/并/或/且**（`\bigcup \bigcap \biguplus \bigsqcup \bigvee \bigwedge`，模板、带上下限） |
| **箭头** | `→ ⇒ ⇐ ⇔ ↔ ↦` |
| **特殊** | `∞ ∂ ∇`（★ 规格《S4》§B 原本就把它仨列在"特殊"里）＋ `∠ △ ⊥ ∥ ° ∴ ∵ □` |
| **线性代数** | **矩阵 / 行列式模板** ＋ `det` `tr` `^T`（转置）`⊗ ⊙` |

#### (3) 你点名的那批东西，逐项归属

| 东西 | 形态 | 归到 |
|---|---|---|
| 分式 `\frac{}{}` | 模板 | **结构** |
| 根号 `\sqrt{}` / n 次根 | 模板 | **结构** |
| 绝对值 `\left|\right|` | 模板 | **结构** |
| 上标 / 下标 | 模板 | **结构** |
| **求和 `\sum`** | 模板（带上下限） | **符号 ▸ 运算** |
| **积分 `\int`** | 模板（带上下限） | **符号 ▸ 运算** |
| **极限 `\lim`** | 模板（带下标） | **符号 ▸ 运算** |
| **连乘 `\prod`**（你说的"批量"若是它） | 模板 | **符号 ▸ 运算** |
| **任意 `\forall`** | 记号 | **符号 ▸ 逻辑集合** |
| **存在 `\exists`** | 记号 | **符号 ▸ 逻辑集合** |
| **集合**（`∈ ∉ ⊂ ∪ ∩ ∅`） | 记号 | **符号 ▸ 逻辑集合** |
| **行列式**（2×2 模板） | 模板 | **符号 ▸ 线性代数** |
| **矩阵**（2×2 模板） | 模板 | **符号 ▸ 线性代数** |
| **德尔塔 `\delta` / `\Delta`** | 记号 | **符号 ▸ 希腊** |
| **阿尔法 `\alpha`** | 记号 | **符号 ▸ 希腊** |

★ **默认单一归属**：每项只进**一个**分类；**少数"两种找法都自然"的**才允许第二归属（见 **(6)**，
目前只批了 6 个 n 元集合算子 + `∴ ∵`）。找不到的一律靠**跨分类搜索**兜底。

#### (4) `keywords`：只影响**搜索**，不影响分类（这条我上一版说错了）

- ★ **"线性代数"既是子类名，也是关键词**（不矛盾）：子类名叫它；同时把 `行列式/矩阵/det` 这些项
  也挂上 `关键词: ["线性代数"]` ⇒ 用户在搜索框打"线性代数"能直接出它们（不管当前筛选是什么）。
- `keywords` 的用途只有三样：搜索命中、搜索排序、将来的"相关推荐"——**永远不参与分类归属**。
- 文档《符号面板与符号表》§三说的"内部关键词（线性代数→行列式/矩阵）"就是这个意思。

#### (5) ★ 允许**一项多类**（2026-10-17 用户定：可以，但别太多）

- 数据：主归属仍是 `group` / `subgroup`；新增可选 **`alsoIn: ["符号/运算", …]`**（格式 `一级/子类`）。
- 筛选判据：`分类/子类` 命中 **任一个**归属即显示（主 + alsoIn）。
- **只给"两种找法都自然"的少数项**用（目前就下面这些），否则会造成"同一屏里出现两遍"的困惑：

| 项 | 主 | alsoIn | 理由 |
|---|---|---|---|
| `\bigcup \bigcap \biguplus \bigsqcup`（多集合的交/并） | 逻辑集合 | 运算 | 语义是集合运算，形态是 n 元算子（用户原话："有点类似于集合的求和"） |
| `\bigvee \bigwedge`（多"或"/多"且"） | 逻辑集合 | 运算 | 同上 |
| `∴ ∵`（所以/因为） | 特殊 | 逻辑集合 | 推理记号，两处都有人找 |
| `\sigma`（标准差）· `\mu`（均值） | 希腊 | —（先不双归属） | 等有"概率统计"子类再说 |

#### (7) ★ 搜索关键词：给哪些东西打（我的建议，按"三类来源"）

**原则**：关键词挂在**最可能被搜的那一项**上，**不要撒得太散**（否则搜"线性代数"出三十个结果等于没搜）。

**① 口语 / 同义（每个常用项 1–3 个）**

| 项 | 关键词 |
|---|---|
| `∑` | 求和 · 累加 · 连加 · sigma |
| `∏` | 连乘 · 累乘 · 求积 |
| `∫`/`∬`/`∮` | 积分 · 定积分 · 不定积分 · 微积分 |
| `\lim` | 极限 · 趋近 · limit |
| `∀` | 任意 · 全称 · 所有 |
| `∃` | 存在 · 至少一个 |
| `∈`/`∉` | 属于 · 不属于 · 集合 |
| `⊂`/`⊆` | 子集 · 包含于 |
| `∪`/`∩`/`∅` | 并集 · 交集 · 空集 |
| `≤`/`≥`/`≠`/`≈` | 小于等于 · 大于等于 · 不等于 · 约等于 · 近似 |
| `\bigcup`/`\bigcap` | **批量 · 多个集合 · 求并 · 求交 · 并 · 交** |
| `\partial`/`\nabla` | 偏导 · 偏微分 · 梯度 · 散度 · 旋度 |
| `\to`/`\Rightarrow`/`\Leftrightarrow` | 趋近 · 推出 · 蕴含 · 等价 · 充要 |
| `\pm`/`\times`/`\div` | 正负 · 加减 · 乘法 · 叉乘 · 除法 |

**② 学科 / 场景（**这是"内部关键词"最值钱的部分**）**

| 关键词 | 挂在哪些项 |
|---|---|

### 6.6 ★ 页面位置：`pageXDock`（0..1）取代 `pageOffsetLeft`（bool）

用户 2026-10-17：「页面位置可以做成一个**横条，支持滑动**，可以调整页面中心横坐标。」

- 语义：**在可用空间里的归一化位置** —— `0` 贴左（= 老的"偏左"，`pageOuterMargin = 24`）· `0.5` 居中 · `1` 贴右。
- ★ 为什么存**比例**不存像素：窗口一变、面板一开一关，像素就错；比例不会。
- ★ 红利：**"都收起 ⇒ 页面回居中"不用额外的布尔量** —— 可用空间变大，`0.5` 自动真的在正中。
  （但 `0` 仍然贴左 —— 这是用户选的，不是 bug）
- ★★ 守卫（`editor_layout_test`）：**任何 dock 值、任何开关组合下 `EditView` 宽恒 = 793.7**，变的只有 x。
  实现 `LayoutMetrics.pageLeft(availableWidth, pageWidth, dock)`；**故意不在这里吃掉 `columnGap`**
  （"扣两遍"是本仓踩过的坑）。
- 覆盖式（窄屏）下 dock **强制 0.5**（抽屉只遮不改），设置里的横条在覆盖式下不生效。



| 光标位置 | 动作 |
|---|---|
| **在数学段里**（含紧邻 ±1 格，如刚停在 `$x$` 之后） | **并入那一段**：插 `tex`（`$x+$`），**不**新建第二个 `$…$` |
| **在纯文字里** | **自动建壳**：插 `$<tex>$`（模板 `$\frac{}{}$`），光标进**第一个空槽** |
| **有选区** | 用 tex **替换选区**；选区内已有数学段 ⇒ 替换成 tex、不重复包 |

- 全部走 `insert_guard.planInsert`（行边界 ③④⑤ 照旧）⇒ **一次编辑 = 一步撤销**；
  `EditViewStats.autoWrapped` 记"替用户补了几处编码"。

### 6.7 ★ 诊断清单（b2-② 已落地，《S4》§A4）

**底线原则 5「可疑要可见」的实体**：智能包裹是编辑器替用户猜的编码 ⇒ 必须能点开看。

- 数据源：`lang/math_spans.dart` 的 `scanMathSpans()`（**纯函数**：只认定界符、成对才产出、`\$` 不算、
  行间优先于行内、落单跳过）。`EditView._commitText` / `insertSymbolTex` 各插入路径算出
  `EditViewStats.autoWrappedSpans`（区间 + 源码 + 是否行间）。
- 入口：**状态栏**「自动包裹 N 处 · 查看清单 ›」（`Key('diag-open')`）⇒ 弹窗 `diagnostics_panel.dart`。
- 每条：序号 + 「行内/行间公式 · `<源码摘要>`」+ `偏移 a..b（n 字符）`，**淡红底**（= 这是编辑器猜的）。
- 点一条 ⇒ 关清单 + `EditView.jumpTo(start, end)`：**选中**那一段（高亮，不是只放光标），
  ★ **不写缓冲区 ⇒ 不算一次编辑**（守卫 `diagnostics_test` 盯着 `edits` 不变）。
- 没有可疑项时不显示入口；清单本身也有"这次没有需要你检查的东西"的话术。

### 6.8 ★ 面板长按预览（b2-② 已落地）

- b1 只有 `Tooltip(label + tex)`；现在**长按格子** ⇒ 浮层：**40px 大图** + 名称 + **可选中的 LaTeX 源码** + 「插入」。
  理由：44px 格子里 `\bigcup` 与 `\cup` 那种差别看不出来（`symbolPreview`）。
- ★ **`preview` 字段**（`symbols.json`，可选）：面板/浮层里画**代表式**，插入的仍是**空槽 tex**。
  首例：`cases` = `\begin{cases}x&x\ge 0\\-x&x<0\end{cases}`、`aligned` = `\begin{aligned}a&=b+c\\&=d\end{aligned}`

### 7.1 ★★ 面板插入的「参数安全」三条（2026-10-17 用户手验抓到的真缺陷）

**用户看到的现象**：在公式里点面板符号后，页面出现
`Parser Error: Expected 'EOF', got '#'` ＋ `Can't use function '$' in math mode` ＋ 行间公式退化成正文。
用户以为是"点 `子类` 筛选按钮"导致的 —— **不是**：点筛选只是触发了一次重建，把**已经被打坏的文档**重画出来。

**真凶**在 `applySymbolInsert`（它不经过打字那条 `_needsCommandSeparator`）：

| # | 坑 | 例子 | 修法 |
|---|---|---|---|
| ① | 落在**控制词中间** | `\f\|rac` 里插 `\forall` ⇒ `\f\forallrac` | 挪到控制词**之前**（`\frac` 是一个原子） |
| ② | 与**字母粘连** | `\forall` + `x^2` ⇒ `\forallx^2`（未知命令） | 两侧补**空格分隔**（TeX 里空格不占版面） |
| ③ | 紧贴**命令名 + `{`** | `\frac\|-b…` 插模板 ⇒ `\frac\frac{}{}{-b…}`（外层命令把新模板吃掉）；`…}\|{2a}` 同理 | 挪进那个参数的**开头**（`\frac{\frac{}{}}{-b…}`） |

★★ **守卫是全域的**（`test/lang/symbol_insert_safe_test.dart`）：样本文档的**每一个可达光标位**
（数学段内只取 `caret_sites` 产出的位）× 每种符号 ⇒ 断言"插入后每段数学都能被 KaTeX 解析、
tex 里不混进 `$`/`#`"。**改前 146/804 个落点产出坏文档；修完 0/159 可达落点。**

★ 顺带纠正一条旧断言：`$a\betac$` 是**坏 TeX**（`\betac` 未定义）——老测试把它当成了正确期望。

## 13. ★★ 文件对话框与「自动包裹」入口（F18 / F19，2026-10-21 用户实测）

### 13.1 F19：对话框的**初始目录**

- **用户原话**：「现在每次导入导出保存，好像弹出的框强制默认是在软件所在文件夹？
  但是实际使用的时候用户肯定不会把文件放在软件的文件夹的吧」
- **根因**：三个原生对话框（打开 / 保存 / 选目录）**都没传 `initialDirectory`**
  ⇒ Windows 用**进程当前目录**（= exe 所在目录）当地点。
- **口径（新）**：一律走 `io/dir_memory.dart` 的 `DirMemory` ——
  **有"上次用过的目录"就用它；没有就落到用户的「文档」目录**（`%USERPROFILE%\Documents`，
  不存在则退回用户主目录）；两者都没有才交回系统默认。
- 记忆落在 `AppSettings.lastDir`（跟设置一起持久化），由 `EditorPage` 在
  `initState` 里 `load`、拿到恢复出来的设置后再 `load` 一次，并挂 `onChanged` 落盘。
- 记忆时机：**选完文件**（取父目录）/ **选完目录**（就用它）；同一目录重复选**不重复写盘**。

### 13.2 F18：「自动包裹 N 处 · 查看清单 ›」必须真的进状态栏

- **用户实测**：导入一份裸 LaTeX 的 txt，底部浮条写着「智能包裹 6 处」，
  但**状态栏没有那一条** ⇒ 「查看清单 → 跳转并高亮」**没有入口**。
- **根因**：`EditViewStats.autoWrapped` 只由**粘贴链**（`_commitText → _stampWrapped`）盖；
  导入走 `loadDocument`（整篇替换）**从不经过那条链** ⇒ 计数恒为 0；
  而 F2 的 `docEpoch` 清零又保证每次导入都被清一遍。
- **口径**：**任何"编辑器替用户补了编码"的入口都要把记账交给编辑层**。
  导入用 `EditViewState.noteExternalWrap(n, spans:)`（在 `loadDocument` **之后**调，
  因为 epoch 变化会清零）；`spans` 按**内容匹配**定位（导入是整篇替换，
  包裹计划里的偏移属于原文，不能直接用）。
- 反例（守卫盯着）：导入一份**已规范**的 md（没补任何东西）⇒ 状态栏**不出现**那一条。

## 14. ★★ 面板 / 快捷栏的**键盘流**（U2，2026-10-21 用户拍板）

### 14.1 两条定死的口径

1. **`Ctrl+/` 保持纯开关、不抢焦点**。用户理由（原话大意）：「熟练的人可能不需要搜索框，
   保持光标在编辑页，点选符号其实更快捷」⇒ 开面板**不许**动焦点。
2. 想用键盘时按**显式入口**（按了才把焦点交出去，`Esc` 立刻还给编辑器）：

| 动作 | 默认键 | 说明 |
|---|---|---|
| **进入符号面板（键盘流）** | **F6** | 面板没开就顺带打开；焦点落在网格第 1 格 |
| **进入快捷栏（键盘流）** | **F7** | 焦点落在快捷栏第 1 格 |

★ 这两条进**快捷键表**（`kShortcutActions`，48 条全部 `wired`），因此**可改键、可停用**。

### 14.2 焦点内的**局部键**（不进快捷键表，不可改键）

**面板里**：`← ↑ → ↓` 移动高亮格 · `Enter` / **空格** 插入当前格（用户选"甲"：
空格与回车同义，插完焦点留在面板可连插）· `1–8` 直接跳第 N 格 · `Tab` 去搜索框（打字即筛选）·
`Esc` 退回编辑器（**面板不关**）。

**快捷栏里**：`← →` / `1–8` 选格 · `Enter` 进入赋值模式（等价点一下空格）· `Delete` / `Backspace`
清空该格（替代"长按清空"）· `Esc` 退出。

★ 这些键以**只读**形式列在 设置 → 快捷键 页的「**焦点内（面板 / 快捷栏）**」一节
（用户要求：「在设置的快捷键界面标明这些」）——不参与改键与冲突检测。

### 14.3 焦点必须**看得见**

当前格画 **2px 蓝边（`#1E88E5`）+ 淡蓝底（`#EBF5FF`）**，与编辑器光标的蓝同色；
快捷栏的选中格同色系描边（赋值模式的橙色提示优先）。
