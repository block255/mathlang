# S4 · 语言层与输入层（设计稿）

> 目标：**用户永远不写 LaTeX**。用户/教师/AI 给的东西（纯文本、裸 LaTeX、粘贴、拍照识别后的 txt）
> 进来之后，**由编辑器负责编码**；用户只做"看得见的动作"（打字、点选、拖选、快捷输入）。
>
> 前提：M1+M2 已收口（结构几何 / 点哪落哪 / 看得见 / 选择与剪贴板 / 空行）。
> 本文只记 **S4** 的决策与批次规格；位点/结构那些在《位点与结构导航.md》。

## 一、五块内容（2026-10-17 用户拍板）

| 块 | 内容 | 关键口径 |
|---|---|---|
| **A 输入情景适配** | 多行粘贴/导入 · **裸 LaTeX 智能包裹** · 诊断清单 · 一步撤销 | **智能包裹没有开关**（它是"数据进门"的基础设施） |
| **B 侧边面板** | 分类（最近/收藏/结构/符号[带子类]/AI 常用）· 搜索 · 结构模板进空槽 | **覆盖式**，不挤压 A4 页面（否则分页会跳） |

| **D 导入导出** | 导入 `.txt/.md/.pdf`；导出 `.md/.txt/图片集/PDF` | PDF **只保证自产自销**：导出时把 `.md` 作为**附件**嵌入；导入优先读附件 |
| **E 打磨** | 撤销分组 · 本地暂存（刷新不丢）· 移动端 · 性能 | |

### ★ `/` 转分式（用户纠正过一次，记下来）

- **在任何位置都触发**（文本行 / 数学段内一样）：我们的前提是**同权** ——
  一行文字里出现分式时，**分式自己就是一个整体对象**，不存在"它属于哪个数学段"。
- 触发时把**光标前的那个原子**做成分子、光标进**分母空槽**；**一步撤销**可回。
- **不加"前面必须是字母数字"这类护栏**（用户明确否掉：`考虑这样一个分式a/b……` 会被绊）。
  不想要的用户 ⇒ 到**快捷键设置**里禁用这一条。

### ★ PDF 保真（用户拍板）

- **现在**：导出 PDF 用**图片式**（每页 A4 渲染成 PNG 再装进 PDF，视觉 1:1）+ **把 `.md` 作为 PDF 附件嵌入**
  ⇒ "自产 PDF 导回来无损"靠**读附件**实现（版面里没有 `\frac` 这类语义，靠反推是不现实的）。
- **以后**：**文本式/矢量式 PDF**（文字可选、可搜索）单独排期（S5）。附件方案不影响它。

## 二、S4-a 批次规格（输入情景适配）

### 目标（验收）

把 `test_data/作业辅导1.md`（DeepSeek 辅导微积分原话，LaTeX 是**裸的**）**原样粘贴**进编辑器：

1. 多行的**段落/列表/`$$` 块**结构不被打坏（不能再出现 `Parser Error: Can't use function '$'`）；
2. 裸 LaTeX 被**自动包裹**成行内数学并**正常渲染**；
3. `Ctrl+Z` **一步**回到"粘贴前的纯文本"。

### 四件事

**A-1 多行文本进门不被打坏**（已定位到一半）

- `NewBlockOnEnterFormatter` 是 **diff 驱动**的（只有"真的插入了一个 `\n`"才变成 `\n\n`）✓ 不该背锅；
- 嫌疑在**平台文本通道**：整段多行文本经 `updateEditingValue` 到达时，`\n` 是否被保留；
  以及 `insert_guard.planInsert` 对"含换行的多行插入"的处理。
  ⇒ **先打探针**：在 `updateEditingValue` 与 `_commitText` 各打印一次 `text` 的转义形式，
  粘贴一次就能看出 `\n` 是在哪一层丢的/变多的。

**A-2 智能包裹**（✅ 已完成纯逻辑）

- `lib/lang/smart_wrap.dart`：`planSmartWrap(source)` / `applySmartWrap(source, plan)`；
- 三条原则：**保守优先**（宁可不包）、**证据驱动**（`\命令` / `_` `^` / 关系符）、
  **不碰已有结构**（`$…$`、`$$…$$`、代码块、URL、行首列表标记）；
- 守卫 `test/lang/smart_wrap_test.dart`（7 条，含"纯英文短语不包"“真实语料至少包 4 处"）。

**A-3 接线**：把 A-2 接到**粘贴/导入**这条路上（不是打字路径），并且**整次包裹 = 一步撤销**。

**A-4 诊断清单**（可与 S4-b 的面板一起做）

- 数据：`List<{offset, kind, message}>`（解析错误 / 可疑包裹）；
- 呈现：**不弹窗**；面板里一栏 + 正文里对应位置画淡红底；点一条 ⇒ 光标跳过去。

### 守卫（改前必红）

| 守卫 | 断言 |
|---|---|
| 多行粘贴不新块 | 粘贴 3 段文本 ⇒ 换行数与原文本一致；`$$` 块仍是"一个块" |
| 智能包裹 | 真实语料 ⇒ 包出 ≥4 处；纯英文短语一处都不包；已有 `$…$` 不变 |
| 一步撤销 | 粘贴 + 包裹之后 `Ctrl+Z` **一次** ⇒ 缓冲区回到粘贴前 |
