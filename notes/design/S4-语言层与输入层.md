# S4 · 语言层与输入层 — 设计架构

> **一句话目标**：**用户永远不写 LaTeX**。
> 用户 / 老师 / AI 给的东西（纯文本、裸 LaTeX、粘贴、拍照识别后的 txt）进来之后，
> **由编辑器负责编码**；用户只做"看得见的动作"：打字、点选、拖选、快捷输入。
>
> 状态：**讨论已收敛（2026-10-17）**，本文是 S4 的架构与批次规格。
> 前置：M1 + M2 已收口（结构几何 / 点哪落哪 / 看得见 / 选择与剪贴板 / 空行）。
> 相关：《位点与结构导航.md》（位点与结构）·《编辑地基与手感.md》（手感六组）。

## 0. 不变量（所有批次都不许破坏）

1. **用户不写编码**：界面上不出现 `\frac`、`$`、`{}` 让用户填；编码只出现在"源码视图"。
2. **同权**：**没有"公式块/公式卡"**。一行文字里出现数学时，数学是**这一行的对象**，
   不是一个"公式段"。`/` 在文本行里也直接成分式，就是这条的直接推论。
3. **版面稳定**：面板/快捷栏/高亮/光标**一律不改变正文排版**（A4 分页不能跳）。
   ⇒ 新 UI 必须是 **overlay**，不许挤压页面宽度。
4. **一步可撤**：任何"编辑器替用户做的编码"（智能包裹、`/`→分式、符号替换）都必须是
   **一次编辑 = 一步撤销**。
5. **可疑要可见**：编辑器猜的东西（智能包裹、自动识别）必须能被看到、能改，
   不能悄悄改用户的文字。

## 1. 架构分层

```
┌──────────────────────────────────────────────────────────────┐
│ 输入源                                                        │
│  键盘/IME · 粘贴(剪贴板) · 导入文件(txt/md/pdf) · 面板点选      │
│  · 快捷栏点选 · 快捷输入(/ ^ _ >= …) · 未来：拍照识别            │
└───────────────────────────────┬──────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────┐
│ 语言层（纯 Dart，可单测）                                      │
│  · smart_wrap      裸 LaTeX → `$…$`（**无开关**）              │
│  · shortcuts       快捷输入规则（**可配置/可禁用**）             │
│  · symbol_library  符号/模板库（JSON，含搜索关键词）             │
│  · diagnostics     解析错误 + 可疑包裹 清单                     │
└───────────────────────────────┬──────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────┐
│ 文档层（已有）                                                 │
│  DocBuffer（一维流 + 选区 + 撤销） · 位点表 · 结构单元 · 插入守门 │
└───────────────────────────────┬──────────────────────────────┘
                                ▼
┌──────────────────────────────────────────────────────────────┐
│ 渲染层（已有）                                                 │
│  A4 分页 · 行内数学(按原子) · 行间块 · 光标/选区 · 空槽/位点      │
└──────────────────────────────────────────────────────────────┘
```

★ **分层的硬规矩**：**语言层不许直接碰渲染**，只产出"文本编辑指令"（插入/替换区间）；
渲染层不许知道"智能包裹"的存在。这样每一层都能单独测。

## 2. 五块内容 × 决策记录

下面每块都记三样：**怎么做** / **为什么这样做** / **被否掉的替代方案**。
（被否的方案也要留：下次有人再提同样的，直接翻这里。）

### A. 输入情景适配

| 项 | 做法 |
|---|---|
| **A1 多行文本进门** | 粘贴/导入的多行文本**按文本原样进门**（换行 = 换行/段落），**绝不**触发"Enter = 新块" |
| **A2 裸 LaTeX 智能包裹** | `planSmartWrap(source)` 找出"像数学"的区间，包成 `$…$`；**没有开关** |
| **A3 一步撤销** | 整次粘贴 + 包裹 = **一次编辑** |
| **A4 诊断清单** | 解析错误 / 可疑包裹 都进清单，正文里淡红底，点一条跳过去 |

**A2 的三条原则**（代码里也写着）：保守优先 · 证据驱动 · 不碰已有结构。

- **证据**：`\命令`（词表）· `_`/`^` · 关系/运算符号（`= < > ± ≤ ≥ ≠ ≈ → ∞`）；
- **不包**：纯英文短语（`Cauchy Criterion`、`Bounded Variation`）· 已有 `$…$`/`$$…$$` · 代码块 ·
  URL · 行首列表标记（`1.` `-` `·`）；
- **只在粘贴/导入时跑**（打字不跑）—— 用户打字时**从不写编码**，跑了也没意义，反而会绊。

> **被否**：给智能包裹加"总开关"。
> 理由（用户）：它关系到"能不能正常导入"⇒ **没有商量余地**。想关掉的是 `/` 这类
> **快捷输入**，不是它。

### B. 侧边面板（选取面板）

| 项 | 做法 |
|---|---|
| **位置** | **侧边**（右侧滑出）。文档是**上下翻页**的，侧边观感/操作都更顺 |
| **形态** | **覆盖式 overlay**（不挤压页面 ⇒ 不触发重排/分页跳） |
| **分类** | 最近（MRU）· 收藏 · **结构** · **符号**（带子类）· AI 常用 |
| **符号子类** | 希腊 · 关系 · 运算 · 逻辑/集合 · 箭头 · 特殊（`∞ ∂ ∇`）· 线性代数（行列式/矩阵） |
| **搜索** | 中文名（"任意""德尔塔""积分"）· 英文名 · **拼音首字母** · **内部关键词**（"线性代数"→ 行列式/矩阵） |
| **点选行为** | 符号 ⇒ 光标处插入；**结构模板** ⇒ 插入并把光标放进**第一个空槽**（`Tab` 跳下一槽） |
| **长按预览** | 数学符号按名字找很难 ⇒ 长按/悬停看渲染结果 |

> **被否**：把面板放**底部抽屉**。
> 理由（用户）：编辑器是**一页一页上下排列**的，底部抽屉会和"翻页/滚动"抢动线；
> 侧边更舒服。
> **被否**：挤压式（把正文压窄）。
> 理由：每开一次面板正文要重排、分页会跳 —— 与我们花大力气做的"版面稳定"直接冲突。

### C. 快捷栏 + 快捷键体系

**C1 快捷栏（= 收藏栏）**

- 形态：**面板正上方的 N 格横长条**（N = 面板一排的格数；面板收起来时可独立常驻在页面底部，可隐藏）；
- **赋值方式**（用户给的）：**先点一个栏位"选中"** ⇒ 再点面板里的任意符号 ⇒ **放进这个栏位**（替换旧的）；
- 每格 = 一个"物品"：符号 or 结构模板；
- ★ **默认格数 = 面板符号网格"一排的格数"**（2026-10-17 用户拍板）：两处读**同一个常量**
  `kSymbolGridColumns` ⇒ 栏位与面板首行**逐格对齐**；设置里可调（用户："也许还能够在设置里让用户调"）。
  面板宽度定了，格数就跟着定了 —— **不写死像素**（`_`）的前提是"宽 = N × 格宽 + 间隙"。
- **全局**（不按文档），换文档习惯不变。

**C2 快捷键 / 快捷输入**

一套**默认表**，全部**可改、可禁用**（"不想要"由这里解决，不加护栏）：

| 触发 | 动作 | 触发范围 |
|---|---|---|
| `/` | 光标前**那个可见原子** → 分子，建分式，光标进分母空槽 | **任何位置**（文本行/数学段都一样） |
| `^` `_` | 上下标（已有） | 任何位置 |
| `sqrt` `sum` `int` `lim` `prod`（词触发） | 对应结构模板（带空槽） | 任何位置；★ **必须紧跟终止符**（`Tab` 或空格）才触发，且**整词匹配**（`summer`/`asint` 不触发）；`Tab` 不留下字符，空格**被终止符吃掉**（不进缓冲区）；中文输入法组合中不触发 |
| `>=` `<=` `!=` `+-` `->` | `\ge \le \ne \pm \to` | 任何位置 |
| `1..N`（修饰键） | 快捷栏第 N 格 | 需修饰键（`Alt+1..N`），避免与打数字冲突 |

> **被否**：`/` 只在数学段内触发。
> 理由（用户）：**同权**——文本行里出现分式时，**分式自己就是整体对象**，
> 不存在"它属于哪个数学段"。限制在数学段内会**违背快捷键的初衷**。
> **被否**：给 `/` 加"前面必须是字母/数字"的护栏（避免 `和/或`、`2026/10/17`）。
> 理由（用户）：`考虑这样一个分式a/b……` 这类正常句子会被绊；护栏属于"过度聪明"，
> 不要的就直接禁快捷键。

### D. 导入 / 导出

**导入**

| 格式 | 保真 | 做法 |
|---|---|---|
| `.txt` | 有损 | 走 A1 + A2（智能包裹）⇒ 正常编辑 |
| `.md` | **无损** | 直接进缓冲区（就是我们的语言） |
| `.pdf` | **仅自产无损** | 优先读 PDF 里嵌入的 `.md` **附件**；读不到再退化成"抽文本 + 智能包裹" |

**导出**

| 格式 | 做法 | 备注 |
|---|---|---|
| `.md` | 缓冲区原文 | 无损、可再导入 |
| `.txt` | **字符流原样**（一个 `$` 都不去掉） | ★ 用户拍板 2026-10-17：**追求不丢信息、能够再导入**；txt 本来也渲染不出数学，不为"给人看"牺牲可逆性 ⇒ 与 `.md` **逐字节相同**，只差扩展名 |
| **图片集** | 每页 A4 → PNG | 作业辅导场景**直接发学生** |
| **PDF** | **图片式**（每页 PNG 装入 PDF）＋ **把 `.md` 当附件嵌入** | 视觉 1:1；往返靠附件 |

**为什么 PDF 用图片式 + 附件**

- 我们的数学是 CanvasKit 画的，用矢量 PDF 库**重建**这套排版（数学字体/间距/断行）是另一个大工程；
- 而"自产 PDF 能无损导回"靠**附件**就够（PDF 规范支持 embedded file）：
  附件是**独立数据流**，**不画在页面上**（渲染零影响），zlib 压缩后**大小是噪声级**
  （100 KB 的 md ≈ 30–40 KB，而一页图片通常几十到几百 KB）；
- 坑：某些工具"打印成 PDF/另存"会丢附件 ⇒ 导入时退化成有损路径（不报错）。

> **分阶段**：现在**图片式**；**文本式/矢量式 PDF**（文字可选、可搜）单独排期（S5）。
> 附件方案与它不冲突。

### E. 打磨（同一层，但排在后面）

1. **撤销分组**：连续打字合并成一步（现在每字符一步，长文本撤销很痛苦）；
2. **本地暂存**：刷新/崩溃不丢文档（现在刷新回样本）；
3. **移动端**：软键盘 + 快捷栏尺寸/位置（快捷栏在底部更好按）；
4. **性能**：粘贴 1500 字后的输入帧率（基线：一帧 14.7 ms @ dpr1.5）；
5. **可访问性**：面板/快捷栏的键盘可达（`Tab` 循环 + 回车插入）。

### 4.1 A2 的接线口径（2026-10-17 用户拍板，**别重开**）

1. **只在粘贴/导入入口跑**智能包裹；`updateEditingValue`（打字 / 中文 IME 提交）**不跑**
   —— IME 一次提交一个词，跑包裹会把正常中文误伤成公式。
2. **只产出行内 `$…$`**（用户选 A）：整行"独立式子"要变成 `$$` 显示块，走 **S4-b 的符号面板模板**
   或用户自己 `Enter` 断块（A1 已保证换行不破坏围栏）。**不做**"自动升格成显示块"——
   那会静默重排行间块、可能触发分页变化。

   ★★ **2026-10-17 修订（B′，用户看完实际粘贴效果后拍的板）**：上面那条"只产出行内"**作废**。
   实测：`\sum_{k=1}^n` 包成行内时上下限**画在右边**（n 元算子只在 display 堆叠），
   作业答案里"独立成行的推导"应该居中成块。**新口径**：
   > **整行只有一个式子**（整行除首尾空白外都被这一处包住）**且**含"显示倾向"的证据
   > （`\sum`/`\prod`/`\int`/`\frac`/`\left`… 或关系符 `=`/`≤`/`≥`/`→`）⇒ 包成 `$$\n…\n$$`；
   > 其余一律行内。
   ⇒ "行内夹在文字里的 `a_n`" 永远保持行内（同权原则不变），只有**整行推导**升格。
   ★ 代价（诚实记账）：行间块更高 ⇒ **可能触发分页变化**，用户验收时看一版。
3. **包裹结果必须可见**（原则 5）：走**状态栏**计数（`EditViewStats.autoWrapped` ⇒ 「自动包裹 N 处」），
   **不进正文流**（不触发重排/分页）；正文里的淡色提示留给 A4 诊断清单一起做。
4. 顺序：**先包裹、再算落点** —— 包裹出来的 `$…$` 仍是单行内联，所以 `insert_guard` 的
   ③④⑤ 对**包裹后**的文本照样生效（`edit_view_test` 有一条专门钉这个）。

## 6. 决策记录（2026-10-17 晚，用户逐条拍板；**别再重开**）

1. **`.txt` 导出 = 原样保留 `$`**。用户原话："txt 导出保留吧，反正如果要常态可读肯定是不会 txt 导出的，而且 txt 导出，数学符号也渲染不出来，所以追求不丢信息，可以保留，能够再导入。"
   ⇒ 推论：`.txt` 与 `.md` **同内容**（同一根字符流），意义只在"给别的工具看的扩展名"。
   ★ 因此**不实现**"去 `$` 版"——若将来真要"可读纯文本"，那是 **S5 的文本式导出**，不是 `.txt`。
2. **快捷栏默认格数 = 面板一排的格数**，**同一常量**（`kSymbolGridColumns`），并**在设置里可调**。
   用户原话："其实可以对齐选择面板一排的格数，（也许还能够在设置里让用户调？）"。
   ⇒ 推论：面板宽度不能先写死 320 再让栏位去凑；**先定格数/格宽，再由 N 推算面板宽**。
3. **词触发（`sqrt`/`sum`/`int`…）属于「快捷键系统」的一条条目**，不是智能包裹的开关。
   用户原话："是在定义快捷键是吧，可以。" ⇒ 每条都**可改、可禁用**；**必须终止符收尾 + 整词匹配**
   （否则英文单词里的 `sum` 会误触）；**默认开**（否则"不写 LaTeX"这条主路等于没开），
   误触就由用户在设置里关掉 —— 与 `/`→分式"不加护栏"同一条口径（《快捷键系统》§一 "缩写展开默认关闭"
   说的是**LaTeX Suite 式无白名单的任意 snippet**，与本条的白名单词表不是一回事）。
