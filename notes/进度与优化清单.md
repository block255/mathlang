## 3. 这个阶段的节奏（与开发守则 §六 配套）

1. **你报现象**（越具体越好：点了哪里、期望什么、实际什么、能不能稳定复现）；
2. **我先定位根因**（写探针、看数据，不做表面修补；不靠猜）；
3. **对齐修法**（改什么 / 影响面 / 怎么验收），你说"可以"；
4. **一批实现 → 一次验证**（`analyze` + 全量测试 + 改前必红的变异证据）；
5. **收尾三件套**：设计稿回写 → 交接快照 → 提交。

★ 优先级判据：**"影响每天都用" > "影响偶尔用" > "纯观感"**。
★ 一次只动一处**语义**：同一份语义如果有两条写入路径，必须走同一个判据（本仓已经栽过三次）。

## 4. 试用验收清单（按分区，勾一条代表"我试过且没问题"）

> 用法：试用时对着这张表走；**发现问题就记到 §7**，别直接改代码。

### 4.1 文档与文件
- [ ] 新建（有改动时先问"要不要保存"；取消则什么都不发生）
- [ ] 打开 `.md` / `.txt`；打开后 dirty 点应为 `○`（已保存）
- [ ] 保存（已有路径**直接写回**、不弹框）；`Ctrl+S` 同上
- [ ] 另存为（`Ctrl+Shift+S`）能选新位置
- [ ] 改标题 ⇒ 断掉旧路径（下次保存会问存哪儿）
- [ ] 导入 `.md`（原样）/ `.txt`（智能包裹，报"包裹 N 处"）；**path 为空**
- [ ] 导出 `.md` / `.txt`（两者逐字节相同）
- [ ] 导出**图片集**（选目录 ⇒ `文档名-第01页.png`…）
- [ ] 导出**PDF**（图片式 + md 附件；用阅读器打开，附件里有 `.md`）
- [ ] 文件读写失败时**弹错误框**（可选中复制原因）
- [ ] 关掉再开 ⇒ **内容还在**（本地暂存），顶栏有「已恢复上次编辑」
- [ ] 设置页「高级」能看到暂存路径/时间，「清除」后再开是空白

### 4.2 编辑手感
- [ ] 中文输入法：候选框**贴着光标**；选字不丢字；拼音不会进正文

- [ ] `Ctrl+Z` 一次撤掉"一口气打的那串"；`Ctrl+Shift+Z` / `Ctrl+Y` 重做
- [ ] 点哪落哪：文字/公式/分式右侧空白/行末空白

- [ ] `Ctrl+A/C/X/V`；粘贴多行文本不破坏 `$$` 围栏
- [ ] 失焦不画光标与选区；光标 530ms 闪烁

## 6. 优化候选（按"影响每天都用"排序）

1. **性能**：Windows 上的 AOT 真实数字（用现成的 `FrameTiming` 基准）；长文档（>5 页）打字帧率；分页耗时（现在全量测量）
2. **可访问性 / 键盘流**：面板与快捷栏的 `Tab` 循环 + 回车插入（现在只能点）
3. **移动端**：软键盘、快捷栏底部、fit-width 缩放
4. **手感细节**：光标两侧竖直中心那 3px 偏差（文本侧行盒居中 vs 数学侧基线摆）
5. **视觉**：页边距/页眉的最终配色与字号（等试用反馈）
6. **工程**：`flutter test` 里"量几何"必须装真实字体（已有 `test/support/math_fonts.dart`，新测试别忘）
