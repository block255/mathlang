### 10:50–11:10 · S2-1 块模型与 md 往返

  → 修正：块边界**不是规则清单，而是状态机**。
- ❌ 我原来把"段落 / 引用"整块当 1 个 FlowUnit → 多硬换行的段落必然超页、天天弹告警。
  → 修正：**FlowUnit 按源行拆**（列表按项拆）。
- ✅ 定下 **`Enter` 语义（选 A 空行分段）**：`Enter` 写 `\n\n`、`Shift+Enter` 写行尾两个空格。
  理由：md 会把连续行合并成一段，若"什么都不写"则**往返直接坏掉**。
- ✅ 定下**有序列表写真实序号** `1. 2. 3.`（人 / AI 读文件自然），插入删除后在**提交点重排**。

**产物**：`lib\core\{doc_buffer,block,doc_settings}.dart` + 49 条单测（R0–R8 每条一条）。

### 11:40–12:10 · S2-3 块高测量与分页成本（今天最重要的一段）

原计划"三方案对比"（Offstage / 手工 offscreen pipeline / 渲染后读尺寸）。
浏览器里连续被 `hidden` 打断 → **改搬到 widget 测试**（帧是同步的、可复现、还能留成性能回归测试）。

**结论推翻了原来的框架**：

| 场景（N=25，一整帧） | 缓存关 | 缓存开 |
|---|---|---|
| 对照：什么都不改 | **91 ms** | **2.8 ms**（32×） |
| 增量：只改 1 个单元 | 89 ms | **12.4 ms**（7.2×） |
| 空帧 N=100 | — | 6.1 ms（**O(1)**） |

- ★ `Offstage` 测出的高度与真实渲染**完全一致（0.000 px，25/25）**，成本也相同 → **渲染即测量**，不需要单独一趟测量。
- ★★ **真正的瓶颈是"每次 `setState` 重建整篇"**。解法 = **单元级 widget 缓存**（源没变就复用同一实例）。
- ★★ **缓存必须按「位置」分桶**：只按 `i` 分桶会让同一实例同时出现在 A/C 两列 → 立刻炸 8 次
  `Multiple widgets used the same GlobalKey`。根因：flutter_math_fork 的 `Math` 把 `Line(key: GlobalKey)` **记忆化**了。
  （用二分探针排除了"同一公式出现两次"这个猜想——**那不会**冲突。）
- 附带：**build 比 layout 贵**（冷布局 114.6 → 42.8 ms 全是 build 的节省）→ 优化重点是减少 build。

### 12:10–12:40 · S2-4 A4 分页

**产物**：`lib\layout\{page_metrics,paginator}.dart` + `lib\editor\{unit_pool,page_sheet,doc_view}.dart`
+ 演示页 + 14 + 10 条测试。

- 分页器是**纯算法**（贪心装箱 + 分页符 + 页首丢间距 + 超页不切断 + 告警清单），单独可测。
- `doc_view` 用**双树**：离屏测量树（算高度）+ 每页渲染树（用上次的分页结果）；两棵树**各用各的 widget 池**。
- 打字时序：第 N 帧文字立刻显示、第 N+1 帧页边界落定 → **打字零延迟、分页晚一帧**。

**浏览器验证**：真文档（22 块 / 23 流单元）→ **自动分 4 页**；第 2 页正好从 `<!-- pagebreak -->` 之后的「例 2」开始
（手动分页符生效）；70 行矩阵触发告警「**高于一页（1344 px > 944 px），已强制放在一页内、未切断**」；
页眉、标题、行内/行间公式、列表全部正确。

**测试又抓出一个真 bug**：改 `settings` 时清了 `_layout` 但**没清缓存的高度** → 高度比较判定"没变化" → 提前返回
→ 分页与统计都不更新。已修。

## 今天最值钱的三条经验

1. ★★ **"改设置/换版面"必须让旧的测量缓存作废** —— 否则所有下游（分页、统计）都静默不更新。
2. ★★ **同一个 widget 实例不能放树的两个位置**（flutter_math_fork 内部有被记忆化的 GlobalKey）——
   缓存的粒度是"位置"，不是"内容"。
3. ★★ **Chrome 的遮挡判定会让自动化点击静默失效**；这类"环境假象"要第一时间怀疑，
   并把关键验证搬到 widget 测试里 —— 这一步同时换来了**可复现**和**性能回归测试**。
