## 二、这批交付的东西（按用户能感觉到的分）

| 主题 | 用户看到的变化 |
|---|---|
| **落点** | 打字 / 面板 / 快捷栏 / 快捷键插到**同一个地方**（文末空行不再差一整行）；行内公式末尾 Enter 只下一行；文首打字不多空行 |
| **空行** | 空行里打空格 = 普通段落（空格有宽度、光标跟着走）—— 以前空格打不出、光标消失 |
| **删除** | 删完光标留在**被删那一行**（以前跳下一行，差 38.6px）；删末行也不下跳；删空一段仍收掉它自己的换行（2026-10-28 口径，一次退格 = 那行整体消失） |
| **竖条** | 行内放分式时竖条回**主行带**（以前按分母画）；14–24px 五档字号都验 |
| **表格** | 参差行右侧空白不再跳到块首/块末；列号 / 格子框 / 粘内落格在不等宽表上一致；光标进不了 `\begin{…}`/`\end{…}`（8 种形状） |
| **导入** | 「行内 `$$`」提示只对**解释不了**的 `$$` 报警；合法单行公式块不再误报（真实语料 53 份 / 411 处对账） |

## 三、关键根因（写下来防复发）

1. **同一条事实两处实现**：空行判据 `trim().isEmpty` 与 `blankRunFrom` 各一份，只改一处 ⇒ "改了一处仍然没修好"；
2. **判据靠默认值校准**：竖条"单行段"用 `段盒高 > 1.6em` 猜 ⇒ 16px 默认擦边过、18px 判错（`_lineBoxCenterLocal`）；
3. **几何层补出来的格子没有源位置**：参差行的幽灵格 ⇒ `envCellOffset` 返回 null ⇒ 点击掉到"块前/块后"；
4. **报告器量的是"位置"不是"语义"**：`inlineDoubleDollarLines` 旧判据 = "不在行首就报" ⇒ 合法误报、非法漏报。

## 六、当天下午/晚上追加：**1.3.1**（写作业实战场报的两条）

1.3.0 发出去当天，用户拿它写了一篇作业，只报两条，当天修完并发布 **1.3.1**：

| 条目 | 现象 | 根因 | 修法 |
|---|---|---|---|
| **撇** | `f` 打一个撇正常，**再打撇 ⇒ `[公式不完整]`**（两撇三撇都打不出） | 两个入口每次都插**完整**的 `^{\prime}` ⇒ 同基座两个上标 ⇒ Double superscript；后来又发现"正文起手"这条路更绕：建壳后光标落在 `$` **外面**，面板把整个载荷再塞进公式、键盘则插成文本撇号 | 新增 `lang/prime_merge.dart`：**一律并进往左最近的上标**（可跳过下标组、可跨行内收尾 `$`、裸撇串也能接）；**光标永远"跟随用户位置"**（插入点在自己左边 ⇒ 只是被往后推） |
| **竖条** | 矩阵/行列式/分段里给东西打上标下标、根号次数、log 底时，竖条按"那一格"画（"对标 A 而不是 2"） | `math_caret` 的"格几何接管竖条"两条**无条件**生效，把按层级算好的 `findLocalRowBox` 丢掉；且行间块从没传 `caretDepth` | `doc_view` 补传 `caretDepth` + `math_caret` 加 `cellLevel = depth ≤ 1`（只有格级位点才接管） |

**过程教训（值得记）**：撇这一条前后修了三轮才对准 ——
第一轮修"并上标"（对，但只覆盖"自己打出来的撇"）；第二轮我按"裸撇"假设又改了一版
（本身是真 bug，但**不是用户报的现象**）；第三轮才去**复现用户的真实路径**（正文打 `f` → 面板建壳 → 光标在 `$` 外），
一次命中。**先固定复现件**（`lessons` §二④）不是口号：跳过它就会"改了一个真实但无关的东西"。
