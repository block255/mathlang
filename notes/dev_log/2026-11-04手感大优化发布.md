## 二、这批交付的东西（按用户能感觉到的分）

| 主题 | 用户看到的变化 |
|---|---|
| **落点** | 打字 / 面板 / 快捷栏 / 快捷键插到**同一个地方**（文末空行不再差一整行）；行内公式末尾 Enter 只下一行；文首打字不多空行 |
| **空行** | 空行里打空格 = 普通段落（空格有宽度、光标跟着走）—— 以前空格打不出、光标消失 |
| **删除** | 删完光标留在**被删那一行**（以前跳下一行，差 38.6px）；删末行也不下跳；删空一段仍收掉它自己的换行（2026-10-28 口径，一次退格 = 那行整体消失） |
| **竖条** | 行内放分式时竖条回**主行带**（以前按分母画）；14–24px 五档字号都验 |
| **表格** | 参差行右侧空白不再跳到块首/块末；列号 / 格子框 / 粘内落格在不等宽表上一致；光标进不了 `\begin{…}`/`\end{…}`（8 种形状） |
| **导入** | 「行内 `$$`」提示只对**解释不了**的 `$$` 报警；合法单行公式块不再误报（真实语料 53 份 / 411 处对账） |

## 三、关键根因（写下来防复发）

1. **同一条事实两处实现**：空行判据 `trim().isEmpty` 与 `blankRunFrom` 各一份，只改一处 ⇒ "改了一处仍然没修好"；
2. **判据靠默认值校准**：竖条"单行段"用 `段盒高 > 1.6em` 猜 ⇒ 16px 默认擦边过、18px 判错（`_lineBoxCenterLocal`）；
3. **几何层补出来的格子没有源位置**：参差行的幽灵格 ⇒ `envCellOffset` 返回 null ⇒ 点击掉到"块前/块后"；
4. **报告器量的是"位置"不是"语义"**：`inlineDoubleDollarLines` 旧判据 = "不在行首就报" ⇒ 合法误报、非法漏报。
