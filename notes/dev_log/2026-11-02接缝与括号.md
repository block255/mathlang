## 一、根因（一句话版）

| 现象 | 机制 |
|---|---|
| 极限后按 `^`，公式掉到下一行 | 载荷被规则 ①b 推出公式，规则 ⑤ 再补 `\n` |
| `ln(...)` 后按 `^`，变成 `$$…$$` 行间块 | `wrapNewInlineMath` 把已带 `$…$` 的载荷**再包一层** |
| `[$\alpha$]` / `{$\alpha$}` 变成 `$(\alpha)^{}$` | 重建时写死 `(...)`；`{}` 在数学里还是分组（不画字形） |
| `(x + a)` 的裸空格进数学 | 正文空格原样搬进 math ⇒ 同像素两站 + 删不掉的隐形字符 |

## 四、这一批的方法教训

1. **只测 plan 层不够**：`script_base_bracket_test` 以前只断言 `planAutoExpand` 的返回值，
   所以"计划层绿、落盘层坏"藏了一整晚。这次补了**端到端**（真按键 → 文档 → 撤销）。
2. **"围栏不是操作边界"要落到落盘**：两段相邻行内公式在存储上会撞成 `$$`；
   合并围栏（只移动 `$`）比塞一个空格更符合这条原则。
3. **`{}` 在正文与数学里不是同一个东西**：正文 `{}` 是可见字符，数学 `{}` 是分组（不画字形）
   ⇒ 搬进数学必须转义。
4. **`\ ` 是控制词分隔符**：因此"空白一律转 `\ `"不需要给 `\alpha x` 这类命令名单独开后门。
5. **计划层的"改内容"护栏要按语境窄化**：字体变化在 B2-b 已按语境接受；
   真正该拦的是**空格丢失**与**结构变化**（见 `handover/20261102-R甲调查.md` §6.5）。

## 六、补批：括号对必须同层（2026-11-02 晚，`cb5dc1a`）

> 用户手验时发现：**自然打字**会形成"`(` 在公式里、`)` 在公式外"——按 `^` 只能写字面量。
> 用户明确指出：**不该让用户改写法**。⇒ 根因改判到**输入层**，当批补掉。

### 6.1 规则

打**闭合**括号时，找配对开括号；若它在**另一层**、且闭合括号**紧贴**公式边界（中间没有别的文字）
⇒ 把闭合括号落到**开括号所在的层**：

- 开在数学、`)` 打在正文（紧跟收尾 `$`）⇒ `)` 落进公式（`contentEnd`）；
- 开在正文、`)` 打在数学里（正好在收尾 `$` 之前）⇒ `)` 落到公式之后（`closeEnd`）；
- 中间夹文字 / 行间围栏 ⇒ 不动。

实现：`render/insert_guard.dart` `planInsert` 在 `_planCore` 之前调 `_bracketLayerFix`；
`_matchedOpenFor` 的 `depth` 从 **1** 起（被插入的闭括号本身不在文档里，否则会把已配平的内层括号当目标）。

### 7.1 三种形状（同一句：极限 + 括号分式）

| | 形状 | 怎么处理 |
|---|---|---|
| **A** | `$\lim…$($\frac…{2}$)` —— 括号**全在正文**，里面恰好一整段公式 | 升格 + 接缝「乙」⇒ `$\lim…(\frac…{2})^{2}$` |
| **B** | `$\lim…(\frac…{2})$` —— 括号**全在数学**里 | 走"并回原段"，`^` 直接挂到 `)` 上 |
| **C** | `$\lim…(\frac…{2}$)` —— **括号跨围栏**（收尾 `$` 夹在括号里） | **输入层禁止**：打 `)` 时落到开括号那一层；旧 C 文档不兜底 |

### 7.2 判据（括号里有啥 ⇒ 怎么处理）

| 括号内容 | 处理 |
|---|---|
| 恰好一整段 `$…$` | 内联成一段（括号种类保真） |
| 纯正文（无 `$`） | **整对升格**（A 方案）；空白 → `\ ` |
| 混着正文 / 两段公式 / 空段 | **不升格**（写字面 `^` / `_` / `'`；可见的拒绝，不静默改内容） |
| ASCII `{` `}` | 必须转义成 `\{` `\}`（数学里 `{}` 是分组、不画字形） |
| 全角 `（）［］｛｝` | 认（字符类规则） |
| 中文 | 允许进数学（B2-b 同一口径）；**不生成 `\text{}`** |

### 7.3 接缝：**乙（合并围栏）**

- 左/右**紧贴**一段行内公式 ⇒ 合并围栏（只移动 `$`，**零新增字符**）；
- 邻居是文字 / 行首 / 行尾 ⇒ 直接插（`ln$…$` 不产生 `$$`）；
- **不补换行、不补空格、不造 `$$`**；
- 完整行内公式走 `spliceFencedInline`，**不再走** `applySymbolInsert`（它按裸 tex 处理）；
- 一次编辑 = **一步撤销**。

### 7.4 输入层：**括号对必须同层**

- 打**闭合**括号时，若配对开括号在另一层、且闭合括号**紧贴**公式边界 ⇒ 落到开括号那一层；
- 中间夹着别的文字 ⇒ 不动（搬了会变语义）；行间围栏 `$$` ⇒ 不参与；
- ★ **不要求用户改写法**（用户原话："强行要求用户去调整自己的行为……不太对劲"）。

### 7.5 守卫口径（这次学到的）

1. **计划层 ≠ 落盘层**：只测 `planAutoExpand` 的返回值会漏掉"落盘后多一个换行/ `$$`"；
   必须**端到端**（真 `EditView` + 真按键 → 文档 → 撤销）。
2. **改前红**：回退生产代码跑；接缝批 ⑨–⑮ **9 红**、端到端 **8/9 红**；同层批 **9 红**。
3. **全域断言**：产物无新增 `\n`、无 `$$`、括号种类不变、空白归一、一步撤销。
4. **文档形态也是行为**：`$` 的位置会被用户看见（字体 / 换行 / 行间块），所以要测。
5. **拒绝要"响"**：挂不上就写字面量（可见），不许静默改内容。

### 7.6 明确不做（边界）

- 统一升格（混合 / 两段 / 嵌套括号）—— 另立项；
- `\text{}` 方案 —— 否（与"编辑器从不生成 `\text{}`"冲突）；
- CJK 护栏 —— 否（B2-b 已接受）；
- §4.2「面板插入时把括号并进公式」—— 不做；
- 旧 C 文档兜底 —— 不做（用户确认测试文档不用救）。
